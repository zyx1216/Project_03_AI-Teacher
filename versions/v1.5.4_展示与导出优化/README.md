# 📐 AI教学辅助

面向中小学教师的本地智能教学工具，把 **AI 备课、智能出题、作业设计、成绩分析、错题整理** 放在一个桌面应用里。支持语文、数学、英语、物理、化学、生物、政治、历史、地理 9 个学科。

应用为单机运行：无多用户、无登录、无云部署，数据库、上传资料、配置和向量索引都保存在本机 `data/` 目录。

## ✨ 功能亮点

- **AI 备课**：上传 PDF/Word、粘贴文本或导入网页链接，结合 RAG 检索生成结构化教案。
- **教案编辑与导出**：教学目标、重难点、教学过程、板书设计、作业布置均可在线编辑并导出 Word。
- **AI 出题**：按知识点、题型、难度和数量生成题目，答案为空自动拒收，数学题支持 SymPy 验算。
- **作业设计**：支持题库选题、AI 即时出题、外部导入、手动加题和自动组卷，可生成学生卷、教师卷和 PPT。
- **成绩管理**：支持 Excel/Word/PDF 成绩导入，导入时可直接新建考试，也可导出格式化成绩单。
- **考试与趋势分析**：提供平均分、最高/最低分、及格率、优秀率、排名、分数段、学期和学年维度的趋势分析。
- **错题本与重做卷**：逐题批改后自动收集错题，可加入下次作业，也可生成“错题重做卷”。
- **首页与教学日历**：首页展示数据概览、最近动态和待办；教学日历汇总考试、作业和教案。
- **快捷键**：`Ctrl+1/2/3/4` 切换备课、作业、学情、设置，`Ctrl+K` 聚焦搜索框。

## 🛠️ 技术栈

| 分类 | 技术 |
| --- | --- |
| 前端界面 | Streamlit |
| 后端语言 | Python 3.11 |
| 数据库 | SQLite + SQLAlchemy ORM |
| AI 接口 | OpenAI 兼容接口，可接入 DeepSeek、通义千问、豆包等 |
| 向量检索 | ChromaDB，支持云端 embedding、本地向量模型和关键词检索三级降级 |
| 图表分析 | Plotly、pandas、NumPy |
| 文档处理 | PyMuPDF、python-docx、python-pptx、openpyxl |
| 其他工具 | SymPy、trafilatura、keyring、kaleido |

## 🚀 快速启动

```powershell
# 1. 创建 conda 环境
conda create -n math_teacher python=3.11 -y

# 2. 安装依赖（国内可加清华镜像）
conda run -n math_teacher python -m pip install -r requirements.txt `
  -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 启动应用
conda run -n math_teacher streamlit run app.py
```

浏览器打开 <http://localhost:8501>。第一次使用时进入“设置”，填写大模型 Base URL、模型名和 API Key；API Key 保存在 Windows 凭据管理器中。

## 🎓 生成示例数据

项目内置虚构示例数据脚本：3 个班、90 名学生、9 个学科、10 次考试。

```powershell
# 只刷新示例 Excel
conda run -n math_teacher python scripts/make_demo_data.py

# 备份当前 data 目录后，清空业务表并写入示例数据库
conda run -n math_teacher python scripts/make_demo_data.py --wipe
```

## 🧠 技术亮点

- **本地优先与隐私**：业务数据留在本机，API Key 不写入项目文件；支持整个 `data/` 目录一键备份和恢复。
- **RAG 三级降级**：云端 embedding、本地 ONNX 向量、关键词检索依次兜底，未配置 embedding 也能备课。
- **显式学科归属**：全局当前学科已移除，各功能独立选择并持久化；创建业务数据时显式传参。
- **答案和题目校验**：无答案题目拒绝入库；题型、难度和知识点统一归一；数学表达式可自动验算。
- **统计口径稳定**：竞赛排名、缺考处理、自定义及格线/优秀线、学期和学年筛选均由服务层统一计算。
- **离线内容生成**：教案 Word、作业两卷、PPT 和学期报告尽量使用本地依赖生成，减少导出环节的外部网络依赖。
