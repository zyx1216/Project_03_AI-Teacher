# AI教学辅助 · 使用说明（v1.4.2）

本手册面向第一次使用的老师。软件在你自己电脑上运行，数据不联网、不上云（除了你主动调用的 AI 模型）。

## 一、启动与退出

### 1. 启动（命令行方式）

打开 Anaconda Prompt（或 PowerShell），执行：

```powershell
conda activate math_teacher
cd D:\Codex\Project_03_AI数学教师工作台
streamlit run app.py
```

启动后浏览器会自动打开 <http://localhost:8501>。没自动打开就手动在浏览器地址栏输入这个网址。

### 2. 在 PyCharm 里启动（推荐配置一次，以后点绿色三角）

1. 右上角「运行配置」→「编辑配置」→ 点 **+** → 选 **Python**。
2. 「运行于」选模块名方式：
   - 模块名填：`streamlit`
   - 参数填：`run app.py`
3. Python 解释器选 conda 环境 `math_teacher`（Python 3.11）。
4. 工作目录设为项目根目录 `D:\Codex\Project_03_AI数学教师工作台`。

> **常见错误**：不要直接点 app.py 的「运行」。那样会出现一堆 `missing ScriptRunContext` 警告，页面功能不正常。**必须用 `streamlit run app.py`。**

### 3. 退出

在运行 Streamlit 的终端窗口按 `Ctrl + C`，然后关闭浏览器标签页即可。数据会自动保存，不用手动存。

## 二、第一次使用（5 分钟配好 AI）

除纯统计、导出等功能外，AI 备课、出题、反思、评语都需要先配模型。

进入左侧「⚙️ 设置」，从上到下三组配置：

| 配置 | 用途 | 建议 |
| --- | --- | --- |
| **主模型** | 考试分析、学情分析、教学反思、期末评语、作业 AI 总结 | DeepSeek `deepseek-chat`，或通义/豆包 |
| **内容生成模型** | AI 教案、AI 出题、自动组卷补缺 | 可与主模型相同；留空则自动用主模型 |
| **向量模型 Embedding** | 上传课本后的语义检索 | 火山方舟 embedding；**不配也能用**，会自动降级为关键词检索 |

填写步骤（以 DeepSeek 为例）：

1. 主模型区：粘贴 API Key → Base URL 填 `https://api.deepseek.com` → 模型填 `deepseek-chat`。
2. 点「💾 保存配置」，再点「🔌 测试连接」，看到“连接成功”即可。
3. 内容模型区留空（自动用主模型），或单独填一个更强的模型。
4. 向量模型可先不配，需要课本语义检索时再回来填。

**Key 存在哪里**：API Key 通过 `keyring` 存在 Windows 凭据管理器（服务名 `math-ai-teacher`），不写进任何项目文件，不会被 git 提交或打进备份包。Base URL、模型名等非敏感配置存在 `data/llm_config.json`。

> 换电脑迁移时：恢复备份 zip 后，Key 需要在新电脑重新填一次（备份不含 Key）。

## 三、📊 学情

顶部 7 个标签页。

### 1. 学生管理

- **Excel 批量导入**：准备一个 Excel，第一行表头含「姓名」（必填），可选「学号/班级/性别/备注」。表头名字写成“名字、学生姓名、name”也能识别。上传后先看**预览和字段映射**，缺姓名的行会标红，确认无误点导入。
- **手动添加**：填表单个新增。
- **直接编辑表格**：下方表格可直接修改六列（姓名、学号、班级、性别、标签、备注），也可用最后一行新增学生；点“💾 保存表格修改”后统一写入。
- **筛选**：支持按班级、姓名/学号关键词、性别（含“未设置”）和标签筛选；标签直接在“标签”列用逗号或顿号分隔书写（如“积极,计算薄弱”）。筛选只影响表格里显示的学生，保存时只同步当前筛选结果，避免误处理不可见学生。
- **删除学生**：在表格里删除行后再保存，会先提示将级联删除成绩和评语，确认后才真正删除。
- **批量删除**：勾选表格最前“选择”列的多名学生，点“🗑️ 批量删除所选”，二次确认后一次删除。
- **查看画像**：表格上方“查看学生画像”选一个学生，点“🔍 查看画像”可直接跳到画像标签页。
- 学生按「姓名 + 班级」判重，重复导入是更新不是新建。

### 2. 成绩管理

- 先在「🗂️ 考试管理」里点 **➕ 新建考试**（弹窗）：名称、日期、年级、学期、各科满分用逐行表格填写：默认有数学一行，可点“➕ 添加学科”，每行设置学科名称和满分；空行会忽略，同学科不能重复，满分必须大于 0。
- **下载模板**：导入区点 **⬇️ 下载 Excel 模板**，模板含姓名、学号、班级和 9 科列，第二行是示例数据；删掉示例行、填好真实成绩即可导入，未填的科目按缺考处理，不会写入 0 分。
- **Excel / Word / PDF 导入成绩**：Excel 里一列姓名，其余每列是一门科目分数（列名如「数学」「数学成绩」都可识别）；Word 需使用真表格；PDF 仅支持有清晰线框的规范表格。上传后进入统一可编辑预览，可直接修改姓名、班级、分数，缺分数格按缺考处理（不计入统计），确认后写库。系统里没有的学生会自动新建；同一考试重复导入会**更新**原分数。
- 如果 PDF 是扫描件、无线框或版式复杂，系统会提示复制到 Excel 后导入，本版不做 OCR。
- **手动录入/修正**：直接在表格里改单个分数。
- 可导出成绩 Excel。

### 3. 考试分析

先用“学期”筛选缩小考试范围（学期为空的旧考试只在“全部学期”显示），再选一场考试（可再选某个班）：

- 指标卡：均分、中位数、标准差、最高/最低、及格率、优秀率、参考人数。
- 分数段柱状图、各科占比图（Plotly，可悬停看数）。
- 排名表：班内并列同名次（如两人并列第 1，下一个就是第 3）。
- **进退步**：与按日期排序的上一场考试对比，进步标绿、退步标红。
- 点「🤖 生成考试分析」可得到 ≤300 字的整体→亮点→问题→建议（需配主模型）。
- **导出学期报告**：先在上方选择具体学期和班级，再点「⬇️ 导出学期报告（Word）」；报告含本学期考试汇总、各科统计、成绩趋势图、高频错题 TOP5 和学生成绩变化。全部学期下不生成。
- 可导出 Word 报告。

及格线默认满分 60%、优秀线 85%；分数段按满分比例自动换算。

### 4. 趋势分析

- 班级均分趋势：每次考试各科均分折线。
- 学生趋势：选任一学生后，在同一张图里显示历次总分和勾选的单科；总分始终显示，单科可用多选框控制，并可在折线图/柱状图之间切换。显示范围默认最近 5 次，也可选最近 3 次 / 最近 10 次 / 全部。缺考科目留空，不会当成 0 分。
- 可勾选「显示下一场预测」，系统用最近 3–5 个有效点线性预测下一场分数；折线图为红色虚线，柱状图为菱形标记。预测仅供参考，缺考不补零。
- 考试分析的分数段图可在柱状图/饼图之间切换，各科均分图可在柱状图/折线图之间切换；学生排名另提供横向条形图。

### 5. 学生画像

选学生后看到：信息卡、各科平均得分率**雷达图**（按得分率画，满分不同也可比）、自动标签（成绩层次、进步趋势、强项/弱项）、历次成绩表，以及「🤖 生成学情分析」个性化点评。

### 6. 教学反思（v1.0 新增）

- 选「单次考试」或「一段时间（起止两场考试）」，选班级。
- 点生成，AI 会结合**考试成绩指标 + 这段时间的作业错题**（错误类型、高频错题 TOP5）写出四段：**成功之处 / 不足之处 / 学生反馈 / 改进措施**。
- 生成后每段都能在线修改，点「💾 保存留档」，以后在“历史反思”里查看、导出 Word 或删除。
- 没有逐题批改数据时，会主要依据成绩分析，并在文中说明缺少作业数据。

### 7. 期末评语（v1.0 新增）

- 选班级、学期、风格（**鼓励 / 中肯 / 严格**）。
- 点「🤖 批量生成全部评语」：系统按学生**逐人调用**模型，有进度条和成功/失败计数，单条失败不影响其他人，失败的可点该行「🔄 重试生成」。
- 每条评语 100–150 字，可直接在框里改；可单条保存，也可「💾 一键保存全部」。
- 评语按「学生 + 学期」留档，同一学生同一学期重新生成会覆盖更新，不产生重复。
- 「📚 常用评语模板库」可增删自己的常用评语（供参考）。
- 点「⬇️ 导出本学期评语 Word」得到按班级、名单排版的评语集。

> 评语和反思只依据库里真实数据生成，不会编造获奖、职务等信息。

## 四、📚 备课

顶部 5 个标签页。

### 1. 资料管理

- 来源类型支持 PDF、Word、直接粘贴文本、网页链接。系统提取纯文本后按「第X章 / 第X节」自动切章节并预览。
- 使用网页链接时，选择「网页链接」，输入 `http://` 或 `https://` 开头的公开文章地址，点「提取并预览章节」。保存的是抓取当天的正文快照，开头会记录标题、来源 URL 和抓取日期。
- 同一网址已经保存过时，系统会直接提示已有资料，不会重复抓取或新建。
- 网页抓取只支持无需登录、正文直接在 HTML 里的公开页面；不支持整站爬取、批量链接、登录后内容、强 JavaScript 渲染页面，也不会下载图片、视频或附件。抓不到时可换链接，或直接复制网页正文后用“粘贴文本”导入。
- 提取的文本存在 `data/uploads/text/`，可随时查看。
- 点「向量化」把资料建索引。检索分三级：云端 embedding → 本地向量模型 → 纯关键词重叠，**没配 embedding 也不影响备课**，只是检索精度不同。

### 2. AI 备课

- 填课题、年级、章节、课时、风格（传统 / 互动 / 探究），可选要参考的资料。
- 生成结构固定的教案：三维目标、重点、难点、教学过程 5 环节（导入/新授/巩固/小结/作业，带分钟数）、板书设计、反思预设。
- 每个模块一个独立编辑框，可逐块修改；点保存留档，之后可导出排版清晰的 **Word**。

### 3. AI 出题

- 选知识点、题型、难度、题量，一次生成 5 道题，每题含题干、题型、难度、知识点、**答案**、分步解析、易错点。
- **没有答案的题一律不入库**（会提示拒收数）；模型给出可计算的算式时用 SymPy 自动验算，显示“通过/不一致/未验算”徽章。
- 生成题默认进「待审核」。

### 4. 题库管理

- 按题型、难度、知识点、审核状态、来源筛选，或按关键词搜索；题目列表默认最新创建的排在最前。
- 可审核（待审核→已审核）、编辑、删除（二次确认）。
- 支持从 **Word / Excel / 直接粘贴** 外部导入题目，缺答案的标红且默认待审核。
- 导出两种 Word：「仅题目」学生卷、「题目+答案解析」教师卷。

### 5. PPT 生成

- 基于已保存的教案，离线生成 .pptx（不额外调用模型）：白底、深蓝标题，固定结构封面→目标→导入→新授→例题→练习→小结→作业。
- 每页要点不超过 5 条、每条截断到 20 字，可用 WPS / PowerPoint 打开二次编辑。

## 五、📝 作业

顶部 4 个标签页。

### 1. 作业管理

- 列表上方可按作业名称关键词、作业类型（预习/课中/课后/复习/试卷）和班级筛选；这三个筛选只作用于普通作业列表，模板仍只按学科显示。
- 点「新建作业/试卷」弹窗：5 种类型（📖预习 / 📝课中 / 📚课后 / 🔄复习 / 📄试卷），总分、用时等默认值随类型自动变，可从已有模板复制题目。
- 进入作业后，题目有 4 个来源：从**已审核题库勾选**、**AI 即时出题**、**外部导入**、**手动加题**。
- 可上下移动题目顺序、设置每题分值，总分实时汇总。
- 选「试卷」类型可点 **AI 自动组卷**：按题型题量和难度配比，从已审核题库确定性抽题，不足的部分调 AI 补齐，并提示知识点覆盖缺口；之后仍可增删调序改分。
- 预览学生卷 / 教师卷，导出两种 Word；可把作业「存为模板」复用；删除有二次确认。
- 列表里可勾选多份作业后“批量删除所选”（二次确认，模板不参与）。

### 2. 成绩录入

- **Excel 导入总分**：一列姓名 + 一个总分列，先预览（缺姓名/缺分标红），确认后写库，重复导入更新。
- **手动录入**：在表格里直接改总分，班内并列排名自动算。
- **逐题批改**：一行一个学生、一列一道题，录「对/错、得分、错误类型」（概念/计算/审题/书写/其他）。这是题目正确率和错题本的数据来源。

### 3. 作业分析

- 提交率、均分、最高/最低、分数段柱状图、班内排名表。
- 与上一份同班作业的进退步红绿标记。
- 每题正确率条形图、高频错题 TOP5（全班错误率 ≥40% 自动标“典型错题”）。
- 「🤖 AI 总结」给出整体→主要问题→教学建议（需配主模型，未配置会明确提示）。
- 可导出 Word 分析报告。

### 4. 错题本

- 逐题批改判错的题自动收集，无需另建错题表。
- 顶部先选学科，再按学生、作业、知识点、错误类型筛选；典型错题置顶。
- 详情含原题、该生作答得分、正确答案、解析（数学公式正常渲染），可导出 Word。
- 每条错题可“➕ 加入下次作业”：题目进页面顶部题篮（去重），之后点“新建作业/试卷”，只要新作业同学科就会自动把题篮里的题带进去；学科不一致会提示且保留题篮。
- 点“🔓 打开这次作业”可直接切到作业管理并打开那次作业。
- 题库管理里多选待审核题可“✅ 批量审核通过”。

## 六、⚙️ 设置与数据管理

### 0. 各功能独立选择学科

v1.3.0 起没有“全局当前学科”。语文、数学、英语、物理、化学、生物、政治、历史、地理 9 个学科的选择器分散在具体功能里，各自记忆、互不影响：

- 备课页：资料管理、AI 备课、AI 出题、题库管理、PPT 生成 5 个 Tab 各有一个“学科”选择器。
- 作业页：作业管理、新建作业/试卷弹窗、错题本各有一个“学科”选择器。
  - 作业列表右上角的“学科”只负责筛选已有作业和模板。
  - 新建作业弹窗里的“学科”只决定这一份新作业的归属，不会改变列表筛选。
- 资料管理切到物理，不会改变题库管理或作业管理的学科；下次重启后，每个功能仍停留在上次选择的学科。
- 新保存的资料、教案、题目、作业会记录当时该功能选择的学科；题库 Word、错题本 Word 的标题和文件名带对应学科名。
- 已打开的作业始终使用这份作业自己的学科，即使作业列表后来切到别的学科，加题、组卷和改分也不会串科。

注意：

- **应用标题/图标始终固定为“📐 AI教学辅助”**，不随学科变化。
- 成绩录入和作业分析不提供学科筛选：作业下拉会显示全部普通作业，并用“[数学]”“[物理]”这样的标签标明学科。
- 历史成绩仍按 Excel 列名识别，可用考试分析的“分析视角”和趋势分析的“科目”选择器查看。

### 0.1 班级管理
- 设置 →「班级管理」可添加预设班级、重命名班级、删除空班级，也可一次选择多名学生批量调班。
- 重命名会同步学生和作业中的班级；删除有学生或作业的班级会被阻止，需先调班或重命名。
- 班级名单存在本地 `data/class_names.json`，不是独立数据表。
- 极早期没有学科标记的资料仍会在数学资料列表中显示；历史题目和作业默认按数学处理。

### 1. 备份（建议定期做）

设置 → 数据管理 →「📦 备份」：

- **生成并下载备份**：把整个 `data/`（数据库、上传资料、向量库、AI 非敏感配置）打成一个带时间戳的 zip，建议存到 U 盘或网盘。
- **在本机留一份**：备份保存在 `data/backups/`。
- 已有的备份 zip 和临时锁文件不会重复打进新包；API Key 不在备份里。

### 2. 恢复（换电脑 / 数据出问题时）

设置 → 数据管理 →「♻️ 恢复」：

1. 上传之前生成的备份 zip。
2. 点确认恢复。系统会先校验压缩包，再把当前 `data/` 整体改名成 `data.bak-时间戳` 留底，然后解包备份。
3. **恢复成功后务必关闭并重新启动 Streamlit**（重启 `streamlit run app.py`），再刷新页面。
4. 换电脑时，恢复后到设置页重新填一次 API Key。

### 3. 清空业务数据（危险操作）

设置 → 数据管理 →「🗑️ 清空业务数据」：

- 删除全部学生、成绩、考试、作业、题目、教案、资料、反思、评语等 **13 张业务表**的数据。
- **保留** AI 配置、API Key、已有备份 zip；数据库表结构不动。

## 七、常见问题

**Q：运行后满屏 `missing ScriptRunContext` 警告？**
A：你直接运行了 app.py。必须用 `streamlit run app.py`（PyCharm 里配成“模块名 streamlit + 参数 run app.py”）。

**Q：AI 按钮点了提示“还没配置 API Key”？**
A：到「⚙️ 设置」填主模型 Key、Base URL、模型名，先点测试连接成功再用。

**Q：提示“找不到这个模型 / 401 / 超时”？**
A：分别核对模型名、API Key、网络与 Base URL；程序已自动重试 2 次，仍失败可换网络或稍后再试。

**Q：网页提示抓取失败怎么办？**
A：先确认链接是 `http://` 或 `https://` 开头、页面无需登录；需要登录或主要靠 JavaScript 加载的页面暂不支持。可以换一篇文章链接，或在浏览器里复制正文，用“粘贴文本”方式导入。

**Q：没配向量模型能备课吗？**
A：能。会自动降级到本地向量、再降级到关键词检索，只是语义检索精度下降。

**Q：PDF 成绩表为什么识别不到？**
A：当前只支持带规范线框的表格 PDF。扫描件、图片型 PDF、无线框排版会提示改用 Excel；可先从 PDF 复制表格到 Excel，整理出「姓名 + 各科分数」后再导入。

**Q：导入成绩后名次、及格率不对？**
A：检查这场考试的「各科满分」是否设对（考试管理里可改）；及格线按满分 60%、优秀线按 85%。

**Q：成绩 / 评语改错了能撤回吗？**
A：单条可直接在页面修正并重新保存（评语按学生+学期覆盖更新）。整库层面建议改动前先做一次备份，必要时用恢复功能回到备份时的状态。

**Q：示例数据在哪？**
A：命令行执行 `python scripts/make_demo_data.py`，会在 `data/uploads/demo/` 生成虚构的 2 班 30 人、3 场考试示例 Excel，按“学生管理→成绩管理”依次导入即可体验完整分析。
