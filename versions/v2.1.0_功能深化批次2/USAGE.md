# AI教学辅助 · 使用说明（v2.1.0）

## v2.1.0 功能深化批次2（补缺）

### 1. 客观题重批
- 进入「📝 学业测评 → 作业管理」，打开作业的「在线提交与批改」区域。
- 点「🔁 重批客观题」会重新判断选择、判断和填空题，提交记录中的客观题百分制分数会刷新。
- 默认跳过已有教师评语的提交；勾选「强制覆盖已有教师评语记录」后才重算这些记录。

### 2. 主观题 AI 批改
- 在同一区域选择解答题，可填写评分标准，点「🤖 批量批改」。
- 页面逐人显示学生答案、AI 得分和评语；教师可直接改成分数和评语，点「💾 保存人工批改」。
- 核对完成后点「✅ 确认并留存批改记录」，系统写入一条 `GradingLog`。空作答记 0 分；AI 结果异常时不会编造分数。

### 3. 抄袭检测
- 点「🔍 检测疑似抄袭」，系统按答案文本相似度输出疑似学生对。
- 每条结果可点「确认」或「排除」；该状态只在当前 Streamlit 会话中保留。

### 4. 完成度分析
- 进入「📝 学业测评 → 作业分析」，展开「📌 完成度分析」。
- 可查看提交率、按时提交率、各题作答率、正确率、平均得分率、平均距截止提交时长。
- 图表可在「各题正确率 / 平均得分率」之间切换；系统按正确率把题目当次表现标为基础、中等或偏难，不改题库难度。

### 5. 单学生个性化作业
- 在「作业管理」底部选择作业学科和学生，可手动指定知识点和题量，点「🚀 生成个性化作业」。
- 不手动指定时，系统只根据该学生真实逐题作答记录找薄弱点；没有逐题数据会提示数据不足。
- 本版只生成单个学生的作业，不一次生成全班作业。

### 6. 资料 ZIP 资源包
- 进入「📚 备课 → 资料管理」，展开「📦 资源包导入导出」。
- 选择资料后可生成 ZIP；ZIP 内包含原始资料文件和 `manifest.json`。
- 导入时按学科、资料名称和文件哈希去重，重复文件会跳过。

### 7. 板书生成
- 在「AI 备课」的已保存教案中展开「✍️ 生成板书」。
- 可选结构化、思维导图、清单式三种风格，生成后能直接编辑 JSON。
- 点「💾 保存回教案」会更新原教案并生成版本；点「⬇️ 导出板书图片」下载 PNG。

### 8. 文本课堂实录
- 进入「📚 备课 → 🎙️ 课堂实录」。
- 粘贴逐字稿，或上传 TXT/MD 文件；本版不支持录音自动转写。
- 点「🤖 生成纪要」后可查看摘要、重点知识、学生互动、课堂亮点、问题和后续建议，并可保存历史记录。

## v2.0.0 功能深化批次1（补缺）

### 1. 题目质量审核
- 进入「📚 备课 → 题库管理」，打开题目详情后点「🔍 质量审核」。
- 页面显示质量分、问题和修改建议；点「🛠️ 一键修复」会生成一道新的修复题，不直接覆盖原题。
- 没配置 AI 时也能检查空答案、空知识点、非法难度和题干过短这些硬伤。

### 2. 题目相似度查重
- AI 出题确认入库、外部题库导入、历年真题导入前，系统会自动查疑似重复题。
- 命中时会提示“疑似重复 #ID”和相似度，默认不入库；确认仍要保存时，勾选「仍保存疑似重复题目」再导入。
- 题目详情里也可以点「🔎 查找相似题」。

### 3. 家校沟通报告
- 进入「📊 学情 → 学生画像」，选择学生后点「📨 生成家校报告」。
- 可直接编辑近期表现、优点与进步、需要改进、家庭配合建议和老师寄语。
- 点「⬇️ 导出 PDF」保存打印版；没有考试或作业数据时会明确提示数据不足。

### 4. 分层作业
- 进入「📊 学情 → 趋势分析 → 🧑‍🏫 班级分层与分层作业」。
- 选择班级、学科和每层题量后，页面按最近一次考试显示 A/B/C 三层名单。
- 点「📚 一键生成分层作业」会生成三份作业：A 层拓展、B 层中等、C 层基础。

### 5. 教案版本对比
- 在已保存教案中点「📜 历史版本」，任选两个版本后点「查看 diff」。
- 差异文本会列出教学目标、重难点、教学过程等部分的新增、删除和修改；也可以继续回退到任一历史版本。

### 6. PPT 内容控制
- 进入「📚 备课 → PPT 生成」，选择教案后可设置：
  - 是否含例题；
  - 是否含练习；
  - 目标页数（0 表示不限制）。
- 页面会优先保留封面、目标页等固定结构，再按目标页数裁剪新知讲授页。

## v1.9.9 趋势图样式优化

### 1. 看趋势图
- 数据看板班级趋势、学情趋势分析（班级整体/学生个人）、知识点掌握追踪的折线图统一优化：
  - x 轴不再显示考试名称，画面更干净；真实考试名、日期都在悬停里。
  - 线和点更粗更大，一眼能看清走向。
  - 鼠标放到某个点上：顶部统一显示这次考试的名称、日期、满分，下面每条线一行给出分数和得分率，不用滚动。
- 多线（多班/多科/学生对班级平均）按“考试名+日期”对齐，某个班缺考就断开，不会错位。

### 2. 显示范围与时间筛选
- “显示范围”选最近 3/5/10 次或全部，x 轴按当前范围从第 1 次编号；再叠加学期/学年等“时间筛选”。
- 切换范围或时间后，范围外的考试不出现，悬停日期正确。

### 3. 原始分 / 得分率切换
- 班级、学生单科默认显示得分率，可切回原始分；总分图始终是原始分（各次考试总分口径可能不同）。
- 学生趋势还可切“柱状图”，柱状模式同样隐藏了 x 轴标签、整图全宽。

### 4. 初中满分口径
- 未单独配置满分的初中旧数据，语文/数学/英语默认满分按 120 计算（高中仍 150）；考试自己填了满分的以考试为准。

## v1.9.8 分数图表满分适配

### 1. 统一满分与得分率
- 跨考试、跨学科、跨满分的分数比较统一看**得分率**（得分÷满分×100%），单科悬停同时显示原始分、满分和得分率。
- 满分来源：①考试自身配置的各科满分；②没配置时按年级默认（初高中语数英 150、其余 100；小学语数英 100）；③都没有按 100。
- 作业满分：优先题目分值之和，其次作业登记总分，都无效按 100；两者不一致时页面提示。

### 2. 数据看板
- 「📊 数据看板」指标卡“平均分”变为“平均得分率”；各科对比、分数段分布、排名均按得分率。
- 班级趋势图可在“原始分 / 得分率”之间切换（默认原始分），悬停同时看原始分、满分、得分率。

### 3. 学情分析
- 考试分析：分数段图改为五段“得分率分段”（不及格/及格/中等/良好/优秀）；各科对比和成绩箱线图均为 0–100% 得分率；排名仍按原始分，悬停带满分和得分率。
- 趋势分析：班级和学生单科默认得分率，可切回原始分；**总分图始终保留原始分**（各次考试科目组合和总分可能不同）。每个单科点悬停显示原始分、满分、得分率；缺数据处折线断开。
- 学生画像雷达按历次考试得分率平均，使用每场考试的实际满分。

### 4. 作业与首页
- 多班级作业对比、作业排名表新增得分率口径；悬停可看原始均分和作业满分。
- 首页“最近 3 场考试”表新增满分和得分率列；平均分卡片仍保留原始分。

## v1.9.7 数据看板 + 智能批改 + API接口

### 1. 教学数据看板
- 入口：侧边栏「📊 数据看板」（学情后、设置前）。
- 顶部可按班级（多选）、学科、考试日期范围筛选。
- 页面自上而下：学生/考试/平均分/及格率/优秀率 5 个指标卡；班级成绩趋势折线、各科均分对比；分数段分布、知识点掌握热力图；学生均分排名、多学科能力雷达。所有图可悬停、缩放。
- 筛选范围内没有成绩时显示空态提示，不报错。

### 2. 作业图片智能批改
- 入口：「📝 学业测评 → 作业管理」，每份进行中作业点「📷 批改」。
- 弹窗里先选学生，再上传作业照片（可多张），选「全部批改」或「仅批改客观题」，点「开始批改」。
- 识别口径：本地 OCR 读图，再由 AI 对答案——选择/填空/判断自动判分，解答题 AI 按评分标准给分和评语。
- 核对逐题得分后点「✅ 确认录入成绩」，成绩写入学情；不满意可「🔄 重新批改」。
- 主观题为 AI 辅助结果，录入前请教师复核。

### 3. REST API
- 先到「⚙️ 设置 → 🔑 API 访问」点「生成 API Key」，复制保存（只显示一次）。
- 启动接口：在同一面板点「🚀 启动API（后台）」，或命令行运行 `uvicorn api.main:app --port 8000`。
- 调用时请求头带 `X-API-Key: 你的key`；文档在浏览器打开 http://localhost:8000/docs （Swagger）或 /redoc。
- 接口能力：学生和成绩的查询/新增、考试分析、AI 出题、AI 备课、健康检查。

## v1.9.6 RAG 知识库 + 多Agent协作

### 1. RAG 课本智能问答
- 入口：「📚 备课 → 📚 RAG知识库」（在“资料管理”之后）。
- 左栏：
  - 多选要检索的本学科资料（可跨多份课本同时检索）；
  - 每份资料显示索引状态、切块数和总字数，未建索引时点「建立索引」，后台线程建立（复用现有 ChromaDB 向量层：云端 embedding → 本地 ONNX → 关键词三级降级）。
- 右栏：
  - 输入问题点「🔍 提问」，答案只依据所选资料生成，找不到依据会明说“资料中没有相关内容”，不会编造；
  - 答案下方给「置信度：高/中/低」和来源章节，点来源可跳到对应资料详情；
  - 「🔄 重新生成」按原问题再答一次；「🧹 清空对话」清空当前问答历史。
- 空资料时提示先到“资料管理”上传，不报错。

### 2. AI 助手直接问课本
- 对侧边栏助手说“从课本里找一下函数的定义”这类话，它自动按当前学科选资料、建索引并作答，结果带【置信度】和来源，可点“打开结果”跳到 RAG 知识库。

### 3. 多Agent模式
- 在侧边栏「🤖 AI 助手」区勾选「🤖 多Agent模式」。
- 三个专业 Agent 分工：
  - 备课Agent：生成并保存教案；
  - 出题Agent：按知识点和难度组卷/补题；
  - 分析Agent：考试分析与薄弱点识别。
- 固化三种协作场景：完整备课（备课→配套题→学情）、考试改进（分析→复习教案→强化题）、分层教学（分层→分层目标→分层作业）。
- complex 任务即便开了多Agent模式，**仍先列计划等你确认**；确认后按 Agent 分步执行：
  - 每个 Agent 的结果可展开查看，支持「🔁 重新执行此Agent」「⏭️ 跳过此Agent」；
  - 单个 Agent 失败时前面已生成的教案、题目保留，可从失败的 Agent 重试。
- 每次协作自动写执行日志（任务、场景、各 Agent 摘要与耗时），供后续查看。

# AI教学辅助 · 使用说明（v1.9.5）

## v1.9.5 自主规划 + 主动提醒 + 教学建议Agent

### 1. 让助手自己拆任务（先确认后执行）
- 对“帮我准备下周的课”“给这个班出一套期末复习卷”“分析这次考试并给出改进方案”这类模糊的复合指令，助手不会直接动手。
- 它先列出一份步骤计划（如：确定范围 → 查资料 → 生成教案 → 布置作业），你确认后才执行。
  - 「▶️ 确认开始执行」：按计划依次执行，进度条显示完成情况，可展开“查看详细日志”看每步输入输出。
  - 「⏭️ 跳过此步」：从下一步开始执行。
  - 「🗑️ 取消全部」：放弃计划，不产生任何改动。
- 执行中途某步失败时，已经生成的教案、题目会保留，可点「🔄 从失败步骤重试」。

### 2. 主动提醒
- 打开首页时，助手自动检查 5 类异常并置顶显示：
  - 班级某科成绩连续三次下降、单个学生成绩骤降（红色）；
  - 作业提交率偏低、本周备课进度落后、知识点题库不足（黄色）。
- 每条提醒可点「去处理」直接跳到对应页面，或点「✅ 已处理」让它不再出现；同一条提醒 24 小时内只显示一次。
- 不想要某类提醒：到「⚙️ 设置 → 🔔 智能提醒」关闭对应开关。

### 3. 本周 AI 教学建议
- 首页「💡 AI教学建议」每周第一次进入时自动生成一次，之后整周读缓存。
- 内容包括本周教学重点、难点突破、分层作业和需要关注的学生。
  - 「🔄 重新生成」：立即刷新本周建议。
  - 「📂 展开详情」：查看教学重点和逐条措施。
  - 「💾 保存到教学反思」：把建议存成一条教学反思，并自动按措施生成改进计划。
- 没有成绩或逐题作业数据时，会提示“需要更多成绩数据”，不会编造建议。

### 4. 分层、复习与个人干预
- 直接对助手说：
  - “这个班怎么分层”：按最近成绩把班级分成 A/B/C 三层，给出各层目标、活动和作业；
  - “快考试了怎么复习”：生成最近一场考试的分天复习安排；
  - “帮我分析张三”：给出该学生的问题诊断、干预措施、家长沟通和跟踪计划。
- 使用分层和复习前，需先在上下文里设置班级。

## v1.9.4 使用说明见下文
# AI教学辅助 · 使用说明（v1.9.4）

本手册面向第一次使用的老师。软件在你自己电脑上运行，数据不联网、不上云（除了你主动调用的AI模型）。

## v1.9.4 上下文记忆 + 多轮修正

### 1. 查看和修改当前上下文
- 侧边栏「🤖 AI 助手」区顶部会显示当前上下文，例如「当前：数学·高一·高一1班」。
- 点「✏️ 修改」可在弹窗里改学科、年级、班级和章节；点「🔄 重置」清空全部上下文。
- 也可以直接输入“记住我现在教高二物理，高一3班”，系统只记住上下文、不执行业务；输入“重置上下文”则清空。
- 上下文保留 30 天，过期自动清空。

### 2. 上下文自动补全
- 设置好上下文后，只说“出5道选择题”，系统会自动带上当前学科、年级和班级，不用每次重复。
- 你在指令里明确写了的学科/年级不会被上下文覆盖，例如上下文是数学，说“出语文题”仍按语文执行。
- 在备课、作业、学情各页面正常操作时，系统会把你选的学科、年级、班级和章节同步为最新上下文。

### 3. 多轮修正试卷
- 生成试卷后，可以直接接着说：
  - “把第2题改难一点”“第1题换成填空题”；
  - “增加2道选择题”“删掉第3题”。
- 修改内容或换题型时，系统不会动原题，而是生成一道待审核的新题替换到这份试卷里，避免影响其他作业。
- 删除题目只把题从这份试卷移除，题库里的原题仍保留。
- 侧边栏会显示“已修正 N 次”。

### 4. 多轮修正教案
- 教案生成后可以直接说“把教学目标改得更具体”“导入环节再精简一点”，系统只改你提到的部分，其余内容保持不变。
- 每次修正都会自动保留一个历史版本，最多 5 个，可在已保存教案的历史版本里查看或回退。

### 5. 修正个人分析
- 学生分析之后，可以说“再看看数学的趋势”（跳到趋势分析并保留该学生）或“加上上一次考试对比”。
- “只看男生”这类当前个人分析不支持的条件，系统会直接说明不支持，不会编造结果。

### 6. 撤销修正
- 每次成功修正后，AI 助手区会出现「↩️ 撤销修正」，最多可逐步撤销最近 5 步。
- 撤销试卷修正会恢复原来的题目关联和分值，但不会删除新生成的题库题；撤销教案修正会回退到修正前内容。
- 执行一条无关的新指令后，原有修正撤销链清空。

## v1.9.3 教学反思改进闭环

### 1. 保存反思
- 进入「📊 学情 → 教学反思 → 反思生成」。
- 按原来的方式选择考试或时间段、班级，生成并编辑四段式反思，然后点「💾 保存留档」。

- 识别后可直接修改章节标题、层级和页码；空标题保存时自动跳过。
- AI 识别失败时仍可用规则切分，不影响资料保存。

## 三、第一次使用（5 分钟配好 AI）

除纯统计、导出等功能外，AI 备课、出题、反思、评语都需要先配模型。

| 配置 | 用途 | 建议 |

| **向量模型 Embedding** | 上传课本后的语义检索 | 火山方舟 embedding；**不配也能用**，会自动降级为关键词检索 |

**Key 存在哪里**：API Key 通过 `keyring` 存在 Windows 凭据管理器（服务名 `math-ai-teacher`），不写进任何项目文件，不会被 git 提交或打进备份包。Base URL、模型名等非敏感配置存在 `data/llm_config.json`。

## 四、📊 学情

顶部 8 个标签页。

### 1. 学生管理

- **Excel 批量导入**：准备一个 Excel，第一行表头含「姓名」（必填），可选「学号/班级/性别/备注」。表头名字写成“名字、学生姓名、name”也能识别。上传后先看**预览和字段映射**，缺姓名的行会标红，确认无误点导入。
- **手动添加**：填表单个新增。
- **直接编辑表格 / 新增**：下方表格可直接修改六列（姓名、学号、班级、性别、标签、备注），表格最后一行可直接填新学生；点“💾 保存表格修改”后统一写入。性别只填“男/女”，其它值会按未设置处理。保存后按“班级 → 学号”自动排序归位。
- **筛选**：支持按班级、姓名/学号关键词、性别（含“未设置”）和标签筛选；标签直接在“标签”列用逗号或顿号分隔书写（如“积极,计算薄弱”）。筛选只影响表格里显示的学生，保存时只同步当前筛选结果，避免误处理不可见学生。
- **删除学生**：在表格里删除行后再保存，会先提示将级联删除成绩和评语，确认后才真正删除。
- **批量删除**：勾选表格最前“选择”列的多名学生，点“🗑️ 批量删除所选”，二次确认后一次删除。
- **查看画像**：表格上方“查看学生画像”选一个学生，点“🔍 查看画像”可直接跳到画像标签页。
- 学生按「姓名 + 班级」判重，重复导入是更新不是新建。

### 2. 成绩管理

- **下载模板**：导入区点 **⬇️ 下载 Excel 模板**，模板含姓名、学号、班级和 9 科列，第二行是示例数据；删掉示例行、填好真实成绩即可导入，未填的科目按缺考处理，不会写入 0 分。
- **Excel / Word / PDF 导入成绩**：Excel 里一列姓名，其余每列是一门科目分数（列名如「数学」「数学成绩」都可识别）；Word 需使用真表格；PDF 仅支持有清晰线框的规范表格。上传后进入统一可编辑预览，可直接修改姓名、班级、分数，缺分数格按缺考处理（不计入统计）。
- 导入时可以二选一：**选择已有考试**，或直接切到 **新建考试**。新建时填写考试名称、日期、年级和学期，系统识别到科目后可逐科调整满分（语文、数学、英语默认 150，其余默认 100）；确认导入时会先建考试再写成绩。同名同日期考试不能重复创建，同名不同日期可以。
- 如果 PDF 是扫描件、无线框或版式复杂，系统会提示复制到 Excel 后导入，本版不做 OCR。
- **手动录入/修正**：直接在表格里改单个分数。
- 可导出**格式化成绩单 Excel**：含标题、姓名、学号、班级、各科成绩、总分、班级排名，末尾附平均分、最高分和最低分。
- “历次考试成绩”折叠区提供跨考试长表，一行是一名学生的一场考试的一科，可按班级、学期、学年、考试类型筛选后导出。
- 也可以先在「🗂️ 考试管理」里点 **➕ 新建考试**：各科满分用逐行表格填写，空行会忽略，同学科不能重复，满分必须大于 0。

### 3. 考试分析

先用“学期”筛选缩小考试范围（学期为空的旧考试只在“全部学期”显示），再选一场考试（可再选某个班）：

- 指标卡：参考人数、平均分、最高分、最低分、及格率、优秀率。
- 分数段图按“未及格 / 及格 / 优秀”三段展示，可切换柱状图或饼图；各科均分图可切换柱状图或折线图；学生排名用横向条形图。
- 排名表和排名条形图都可选择高分到低分或低分到高分；并列同名次规则不变（如两人并列第 1，下一个就是第 3），缺考不参与。
- **进退步**：与按日期排序的上一场考试对比，进步标绿、退步标红。
- 点「🤖 生成考试分析」可得到 ≤300 字的整体→亮点→问题→建议（需配主模型）。
- **导出学期报告**：先在上方选择具体学期和班级，再点「⬇️ 导出学期报告（Word）」；报告含本学期考试汇总、各科统计、成绩趋势图、高频错题 TOP5 和学生成绩变化。全部学期下不生成。
- 可导出 Word 报告。

及格线、优秀线默认分别为满分的 60%、85%；可在本页最顶部的「⚙️ 考试分析线」折叠区调整（空库也能打开），优秀线必须高于及格线。

### 4. 趋势分析

- 顶部两个独立下拉：**时间筛选**（全部 / 某个学期或学年）和**显示范围**（最近 3/5/10 次、全部，默认最近 5 次）。先按时间筛选过滤，再取最后 N 场，过滤后不足 N 场就显示全部；学期/学年按考试日期自动判断，不依赖手填学期。
- 横轴使用“短学期 + 考试名”的唯一名，例如 `26秋·第一次月考`；同一学期出现同名考试时会自动加序号。
- 班级趋势：选择全部科目时分成“各科平均分趋势”和“总分平均分趋势”两张图；选择某一单科时只显示该科。
- 学生趋势：选任一学生后，第一张图显示勾选的各科成绩，第二张图固定显示总分；两张图都可在折线图/柱状图之间切换。缺考科目留空，不会当成 0 分。
- 本版不提供下一场分数预测。

### 8. 知识点掌握分析（v1.5.2 新增）

- 选择一份**已经逐题批改**的作业：系统按题目的知识点标签统计。
- **全班统计**：每个知识点的满分、实得分、得分率和掌握情况（优秀>85% / 良好60–85% / 一般40–60% / 薄弱<40%），以及参与人数；下方自动列出最薄弱的 3 个知识点和改进建议。
- **学生掌握**：选一个学生，逐知识点看他的得分，绿底=掌握好、黄底=一般、红底=薄弱。
- 说明：考试只有科目总分、和题目没有关联，所以知识点分析走“作业逐题批改”，不能直接选考试；一道题打了多个知识点时，这道题的分分别计入每个知识点。没有逐题批改数据时会提示先去打分。

### 5. 学生画像

选学生后看到：信息卡、各科平均得分率**雷达图**（按得分率画，满分不同也可比）、自动标签（成绩层次、进步趋势、强项/弱项）、历次成绩表，以及「🤖 生成学情分析」个性化点评。

### 6. 教学反思（v1.0 新增）

- 选「单次考试」或「一段时间（起止两场考试）」，选班级。
- 点生成，AI 会结合**考试成绩指标 + 这段时间的作业错题**（错误类型、高频错题 TOP5）写出四段：**成功之处 / 不足之处 / 学生反馈 / 改进措施**。
- 生成后每段都能在线修改，点「💾 保存留档」，以后在“历史反思”里查看、导出 Word 或删除。
- 没有逐题批改数据时，会主要依据成绩分析，并在文中说明缺少作业数据。

### 7. 期末评语（v1.0 新增）

- 选班级、学期、风格（**鼓励 / 中肯 / 严格**）。
- 点「🤖 批量生成全部评语」：系统按学生**逐人调用**模型，有进度条和成功/失败计数，单条失败不影响其他人，失败的可点该行「🔄 重试生成」。
- 每条评语 100–150 字，可直接在框里改；可单条保存，也可「💾 一键保存全部」。
- 评语按「学生 + 学期」留档，同一学生同一学期重新生成会覆盖更新，不产生重复。
- 「📚 常用评语模板库」可增删自己的常用评语（供参考）。
- 点「⬇️ 导出本学期评语 Word」得到按班级、名单排版的评语集。

> 评语和反思只依据库里真实数据生成，不会编造获奖、职务等信息。

## 五、📚 备课

顶部 5 个标签页。

### 1. 资料管理

- 来源类型支持 PDF、Word、直接粘贴文本、网页链接。系统提取纯文本后按「第X章 / 第X节」自动切章节并预览。
- 上传文字版 PDF 时直接提取文字，不启动 OCR。
- 上传扫描件 PDF 后会转入后台本地 OCR；切换到其他页面不会中断。备课页的“后台 OCR 任务”会显示“正在识别第 X / N 页...”，返回资料页也能继续查看进度。
- OCR 完成后资料会自动出现在列表中，并把全文保存到 `data/uploads/text/`；确认内容无误后再点“向量化”。若识别失败，可按提示重新上传，或改用文字版 PDF、Word、粘贴文本。
- 使用网页链接时，选择「网页链接」，输入 `http://` 或 `https://` 开头的公开文章地址，点「提取并预览章节」。保存的是抓取当天的正文快照，开头会记录标题、来源 URL 和抓取日期。
- 同一网址已经保存过时，系统会直接提示已有资料，不会重复抓取或新建。
- 网页抓取只支持无需登录、正文直接在 HTML 里的公开页面；不支持整站爬取、批量链接、登录后内容、强 JavaScript 渲染页面，也不会下载图片、视频或附件。抓不到时可换链接，或直接复制网页正文后用“粘贴文本”导入。
- 提取的文本存在 `data/uploads/text/`，可随时查看。
- 点「向量化」把资料建索引。检索分三级：云端 embedding → 本地向量模型 → 纯关键词重叠，**没配 embedding 也不影响备课**，只是检索精度不同。

### 2. AI 备课

- 填课题、年级、课时、风格（传统 / 互动 / 探究），选择资料后勾选要使用的章节和教案模板。
- 生成结构固定的教案：三维目标、重点、难点、教学过程 5 环节（导入/新授/巩固/小结/作业，带分钟数）、板书设计、反思预设。
- 每个模块一个独立编辑框，可逐块修改；点保存留档，之后可导出排版清晰的 **Word**。

### 3. AI 出题

- 选知识点、题型、难度、题量，一次生成 5 道题，每题含题干、题型、难度、知识点、**答案**、分步解析、易错点。
- **没有答案的题一律不入库**（会提示拒收数）；模型给出可计算的算式时用 SymPy 自动验算，显示“通过/不一致/未验算”徽章。
- 生成题默认进「待审核」。

### 4. 题库管理

- 按题型、难度、知识点、审核状态、来源筛选，或按关键词搜索；题目列表默认最新创建的排在最前。
- 可审核（待审核→已审核）、编辑、删除（二次确认）。
- 支持从 **Word / Excel / 直接粘贴** 外部导入题目，缺答案的标红且默认待审核。
- 勾选题目后导出两种 Word：「仅题目」学生卷（含班级姓名得分行）、「题目+答案解析」教师卷；按勾选顺序重新编号。

### 5. PPT 生成

- 基于已保存的教案，离线生成 .pptx（不额外调用模型）：白底、深蓝标题，固定结构封面→目标→导入→新授→例题→练习→小结→作业。
- 每页要点不超过 5 条、每条截断到 20 字，可用 WPS / PowerPoint 打开二次编辑。

## 六、📝 作业

顶部 4 个标签页。

### 1. 作业管理

- 列表上方可按作业名称关键词、作业类型（预习/课中/课后/复习/试卷）和班级筛选；这三个筛选只作用于普通作业列表，模板仍只按学科显示。
- 点「新建作业/试卷」弹窗：5 种类型（📖预习 / 📝课中 / 📚课后 / 🔄复习 / 📄试卷），总分、用时等默认值随类型自动变，可从已有模板复制题目。
- 进入作业后，题目有 4 个来源：从**已审核题库勾选**、**AI 即时出题**、**外部导入**、**手动加题**。
- 可上下移动题目顺序、设置每题分值，总分实时汇总。
- 选「试卷」类型可点 **AI 自动组卷**：按题型题量和难度配比，从已审核题库确定性抽题，不足的部分调 AI 补齐，并提示知识点覆盖缺口；之后仍可增删调序改分。
- 预览学生卷 / 教师卷，导出两种 Word；可把作业「存为模板」复用；删除有二次确认。
- 列表里可勾选多份作业后“批量删除所选”（二次确认，模板不参与）。

### 2. 成绩录入

- **Excel 导入总分**：一列姓名 + 一个总分列，先预览（缺姓名/缺分标红），确认后写库，重复导入更新。
- **手动录入**：在表格里直接改总分，班内并列排名自动算。
- **逐题批改**：一行一个学生、一列一道题，录「对/错、得分、错误类型」（概念/计算/审题/书写/其他）。这是题目正确率和错题本的数据来源。

### 3. 作业分析

- 提交率、均分、最高/最低、分数段柱状图、班内排名表。
- 与上一份同班作业的进退步红绿标记。
- 每题正确率条形图、高频错题 TOP5（全班错误率 ≥40% 自动标“典型错题”）。
- 「🤖 AI 总结」给出整体→主要问题→教学建议（需配主模型，未配置会明确提示）。
- 可导出 Word 分析报告。

### 4. 错题本

- 逐题批改判错的题自动收集，无需另建错题表。
- 顶部先选学科，再按学生、作业、知识点、错误类型筛选；典型错题置顶。
- 详情含原题、该生作答得分、正确答案、解析（数学公式正常渲染），可导出 Word。
- 可导出按学生或按知识点分类的 **PDF**，PDF 中每题展示题干、答案、解析和错误次数。
- 每条错题可“➕ 加入下次作业”：题目进页面顶部题篮（去重），之后点“新建作业/试卷”，只要新作业同学科就会自动把题篮里的题带进去；学科不一致会提示且保留题篮。
- 点“🔓 打开这次作业”可直接切到作业管理并打开那次作业。
- **错题重做卷**：勾选多条错题后点“用勾选错题生成重做卷”，先检查预览表里的难度和分值，确认后生成普通课后作业；同题被多名学生做错只保留一次。修改难度会复制成新题，不改原题。
- 题库管理里多选待审核题可“✅ 批量审核通过”。

## 八、⚙️ 设置与数据管理

### 0. 各功能独立选择学科

v1.3.0 起没有“全局当前学科”。语文、数学、英语、物理、化学、生物、政治、历史、地理 9 个学科的选择器分散在具体功能里，各自记忆、互不影响：

- 备课页：资料管理、AI 备课、AI 出题、题库管理、PPT 生成 5 个 Tab 各有一个“学科”选择器。
- 作业页：作业管理、新建作业/试卷弹窗、错题本各有一个“学科”选择器。
  - 作业列表右上角的“学科”只负责筛选已有作业和模板。
  - 新建作业弹窗里的“学科”只决定这一份新作业的归属，不会改变列表筛选。
- 资料管理切到物理，不会改变题库管理或作业管理的学科；下次重启后，每个功能仍停留在上次选择的学科。
- 新保存的资料、教案、题目、作业会记录当时该功能选择的学科；题库 Word、错题本 Word 的标题和文件名带对应学科名。
- 已打开的作业始终使用这份作业自己的学科，即使作业列表后来切到别的学科，加题、组卷和改分也不会串科。

注意：

- **应用标题/图标始终固定为“📐 AI教学辅助”**，不随学科变化。
- 成绩录入和作业分析不提供学科筛选：作业下拉会显示全部普通作业，并用“[数学]”“[物理]”这样的标签标明学科。
- 历史成绩仍按 Excel 列名识别，可用考试分析的“分析视角”和趋势分析的“科目”选择器查看。

### 0.1 班级管理
- 学情 →「学生管理 → 🏫 班级管理」：班级名单是一个可编辑表格，可直接在“班级名”列改名或用最后一行新增，点“💾 保存班级修改”统一生效；“学生数”自动统计，不用填写。也可一次选择多名学生批量调班。
- 删除班级走表格最前“删除”勾选列 + “🗑️ 删除勾选班级”，需二次确认；为避免误删，保存修改和删除是两个独立操作。
- 重命名会同步学生和作业中的班级；删除有学生或作业的班级会被阻止，需先调班或重命名。
- 班级名单存在本地 `data/class_names.json`，不是独立数据表。
- 极早期没有学科标记的资料仍会在数学资料列表中显示；历史题目和作业默认按数学处理。

### 0.2 考试分析线
- 学情 →「单次考试分析」顶部的「⚙️ 考试分析线」可调整及格线和优秀线百分比，默认 60% 和 85%。
- 设置会保存到本地 `data/analysis_thresholds.json`，考试分析、考试 Word、学期报告和教学反思统一使用。
- 只允许填写 1–99 的数字，且优秀线必须高于及格线。

### 1. 备份（建议定期做）

设置 →「数据备份与恢复」→「📦 备份」：

- **生成并下载备份**：把整个 `data/`（数据库、上传资料、向量库、AI 非敏感配置）打成一个带时间戳的 zip，建议存到 U 盘或网盘。
- **在本机留一份**：备份保存在 `data/backups/`。
- 已有的备份 zip 和临时锁文件不会重复打进新包；API Key 不在备份里。

### 2. 恢复（换电脑 / 数据出问题时）

设置 →「数据备份与恢复」→「♻️ 恢复」：

1. 上传之前生成的备份 zip。
2. 点确认恢复。系统会先校验压缩包，再把当前 `data/` 整体改名成 `data.bak-时间戳` 留底，然后解包备份。
3. **恢复成功后务必关闭并重新启动 Streamlit**（重启 `streamlit run app.py`），再刷新页面。
4. 换电脑时，恢复后到设置页重新填一次 API Key。

### 3. 清空业务数据（危险操作）

设置 →「数据备份与恢复」→「🗑️ 清空业务数据」：

- 删除全部学生、成绩、考试、作业、题目、教案、资料、反思、评语等 **13 张业务表**的数据。
- **保留** AI 配置、API Key、已有备份 zip；数据库表结构不动。
- 需输入“确认清空”并二次确认，防止误触。清空前强烈建议先备份。

### 4. 数据都存在哪

| 内容 | 位置 |
| --- | --- |
| 数据库 | `data/database.db` |
| 上传资料、提取文本 | `data/uploads/` |
| 导出文件 | `data/exports/` |
| 向量库 | `data/chroma/` |
| AI 非敏感配置 | `data/llm_config.json` |
| 各功能学科选择 | `data/feature_subjects.json` |
| 考试分析及格线/优秀线 | `data/analysis_thresholds.json` |
| 课程安排表 | `data/class_schedule.json` |
| 本地备份 | `data/backups/` |
| API Key | Windows 凭据管理器（服务名 math-ai-teacher） |

## 九、常见问题

**Q：运行后满屏 `missing ScriptRunContext` 警告？**
A：你直接运行了 app.py。必须用 `streamlit run app.py`（PyCharm 里配成“模块名 streamlit + 参数 run app.py”）。

**Q：AI 按钮点了提示“还没配置 API Key”？**
A：到「⚙️ 设置」填主模型 Key、Base URL、模型名，先点测试连接成功再用。

**Q：提示“找不到这个模型 / 401 / 超时”？**
A：分别核对模型名、API Key、网络与 Base URL；程序已自动重试 2 次，仍失败可换网络或稍后再试。

**Q：网页提示抓取失败怎么办？**
A：先确认链接是 `http://` 或 `https://` 开头、页面无需登录；需要登录或主要靠 JavaScript 加载的页面暂不支持。可以换一篇文章链接，或在浏览器里复制正文，用“粘贴文本”方式导入。

**Q：没配向量模型能备课吗？**
A：能。会自动降级到本地向量、再降级到关键词检索，只是语义检索精度下降。

**Q：PDF 成绩表为什么识别不到？**
A：成绩表只支持带规范线框的表格 PDF，资料类扫描件 PDF 才会自动 OCR；成绩扫描件、无线框排版仍建议先整理到 Excel，按「姓名 + 各科分数」导入。

**Q：导入成绩后名次、及格率不对？**
A：检查这场考试的「各科满分」是否设对（考试管理里可改）；及格线和优秀线默认按满分 60%、85%，也可在「学情 → 考试分析 → 考试分析线」调整。

**Q：成绩 / 评语改错了能撤回吗？**
A：单条可直接在页面修正并重新保存（评语按学生+学期覆盖更新）。整库层面建议改动前先做一次备份，必要时用恢复功能回到备份时的状态。

**Q：示例数据在哪？**
A：命令行执行 `python scripts/make_demo_data.py`，默认只在 `data/uploads/demo/` 生成 3 个班、90 名学生、10 场考试的虚构 Excel；加 `--wipe` 会先备份、清空业务表，再把 demo 写入数据库。
