## 功能1：AI备课——AI试讲功能

### 1.1 功能位置
在AI备课页（tab_lesson_plan函数内），教案生成并保存后，在"根据教案生成作业"按钮旁边新增"🎭 AI试讲"按钮。

### 1.2 功能流程
1. 用户点击"AI试讲"按钮
2. 弹出设置对话框（st.dialog）：
   - 班级层次选择：基础班 / 平行班 / 重点班（默认平行班）
   - 试讲时长：20分钟 / 40分钟 / 45分钟（默认40分钟）
   - 学生活跃度：低 / 中 / 高（默认中）
3. 点击"开始试讲"后，AI根据教案内容生成试讲脚本
4. 试讲脚本结构：
   - 【课堂导入】（3-5分钟）：导入方式、引导语、预期学生反应
   - 【新知讲解】（15-20分钟）：讲解步骤、关键提问、可能的学生回答、应对策略
   - 【课堂练习】（5-10分钟）：练习题、学生可能出错点、点评方式
   - 【课堂总结】（3-5分钟）：总结要点、布置作业提示
   - 【板书设计】：板书布局建议
5. 生成结果在页面内展示，支持：
   - 导出Word（复用现有export_word逻辑）
   - 复制到剪贴板
   - 重新生成（可调整参数）

### 1.3 技术实现
- 新增服务层函数：utils/lesson_service.py 中新增 trial_lecture(lesson, plan, settings) -> dict
- LLM Prompt设计：
  - 系统提示：你是一名经验丰富的教师培训师，擅长模拟课堂教学。请根据教案生成试讲脚本。
  - 用户提示：包含教案标题、教学目标、教学重难点、教学过程，以及班级层次、时长、活跃度设置
  - 输出格式：JSON，包含import、lecture、practice、summary、board_design五个字段
- 数据库：不需要新表，试讲脚本存在session_state中，不持久化（如需保存可导出Word）

### 1.4 UI要求
- 试讲脚本用st.expander分段展示，每段一个expander
- 关键提问用蓝色高亮，学生可能回答用灰色引用块
- 应对策略用黄色提示框
- 整体风格与现有教案展示保持一致

## 功能2：AI出题——题目变式生成

### 2.1 功能位置
在题库管理（tab_bank函数内），单题查看弹窗中，在"删除"按钮旁边新增"🔄 生成变式"按钮。
同时在批量操作栏新增"批量生成变式"按钮（对勾选的题目批量生成）。

### 2.2 功能流程
1. 用户选中一道题，点击"生成变式"
2. 弹出设置对话框：
   - 变式类型（可多选）：数字变式 / 情境变式 / 难度变式
   - 每种变式生成数量：1-3题（默认每种1题）
   - 难度调整：降低 / 保持 / 提高（仅难度变式有效）
3. 点击"生成变式"后，AI根据原题生成变式题
4. 生成的变式题展示在预览区，每道题有：
   - 题干
   - 答案（含详细解析）
   - 考察知识点
   - 变式类型标签
5. 用户可勾选要保存的变式题，点击"确认入库"
6. 入库的变式题：
   - 自动标注原题ID（parent_question_id字段）
   - 学科、年级、知识点继承原题
   - 状态为"待审核"（与AI出题生成的题目一致）

### 2.3 技术实现
- 数据库修改：questions表新增parent_question_id字段（Integer，可空，外键关联questions.id）
  - 执行ALTER TABLE questions ADD COLUMN parent_question_id INTEGER;
- 新增服务层函数：utils/question_service.py 中新增：
  - generate_variants(question, variant_types, counts, difficulty_adjust) -> list[dict]
  - save_variants(session, variants, parent_id) -> list[int]
- LLM Prompt设计：
  - 系统提示：你是一名资深数学教研员，擅长题目变式设计。变式题必须保持原题的核心知识点，但改变呈现形式。
  - 数字变式：改变题目中的数字，保持题型和结构
  - 情境变式：改变题目背景情境，保持数学结构
  - 难度变式：增加或减少已知条件，改变思维层次
  - 输出格式：JSON数组，每题包含content、answer、analysis、knowledge_point、variant_type

### 2.4 UI要求
- 变式题预览用卡片式布局，每题一个st.container(border=True)
- 变式类型用不同颜色标签：数字变式（蓝色）、情境变式（绿色）、难度变式（橙色）
- 每题有勾选框，底部有"全选"和"确认入库"按钮
- 入库后显示toast提示："已入库N道变式题"

### 2.5 题库管理列表增强
- 题目列表新增"变式"列：如果该题有变式题，显示"有N道变式"，点击可展开查看
- 如果该题是变式题（有parent_question_id），显示"变式自#原题ID"，点击可跳转查看原题
