你是一名资深AI应用开发工程师，同时也是一名资深中学高级教师。你正在开发一个面向中小学教师的AI教学辅助系统。

## 任务目标

本批完成学科深化：备课、作业、学情分析都按当前学科过滤，重新生成全科demo数据。

---

## 具体改动清单

### 1. 备课工作台学科切换

**改动范围：**

| 子功能 | 改动内容 |
|--------|---------|
| 资料管理 | 资料列表按当前学科过滤，只显示当前学科的资料 |
| AI备课 | 生成教案时带上当前学科，提示词里明确学科 |
| AI出题 | 出题时按当前学科，题型、难度、知识点都按学科 |
| 题库管理 | 题库列表按当前学科过滤，只显示当前学科的题目 |
| PPT生成 | 本批不改（用户要求PPT除外） |

**实现方式：**
- 所有查询都加 `subject = app_config.get_current_subject()` 过滤条件
- 新创建的资料、题目自动标记当前学科
- 切换学科后，列表自动只显示对应学科的数据
- 旧数据（没有subject或subject为空的）保留显示，不删除

---

### 2. 作业工作台学科切换

**改动范围：**

| 子功能 | 改动内容 |
|--------|---------|
| 作业管理 | 作业列表按当前学科过滤 |
| 新建作业 | 作业自动标记当前学科 |
| 选题 | 从题库选题时只显示当前学科的题目 |
| AI出题 | 出题按当前学科 |
| 错题本 | 错题本按当前学科过滤 |

**实现方式：**
- Homework表加subject字段（如果还没有的话），新作业自动填当前学科
- 所有查询加subject过滤
- 旧作业数据保留，不删除

---

### 3. 学情工作台学科切换

**改动范围：**

| 子功能 | 改动内容 |
|--------|---------|
| 考试分析 | 单次考试分析增加学科选择器，切换学科看对应科目的分析 |
| 成绩管理 | 成绩列表按学科筛选 |
| 趋势分析 | 趋势图按学科切换 |

**实现方式：**
- 单次考试分析页面加一个学科下拉选择器
- 默认选中当前学科
- 切换学科后，均分、分数段、排名都按该学科重新计算
- 图表也跟着学科变

---

### 4. 重新生成全科demo数据

**改动内容：**
- 修改 `scripts/make_demo_data.py`
- 生成9个学科的成绩数据：语文、数学、英语、物理、化学、生物、政治、历史、地理
- 满分设置：
  - 主科（语数英）：150分
  - 副科（物化生政历地）：100分
- 学生：2个班，30名学生
- 考试：3次（第一次月考、期中、第二次月考）
- 每个学生每科都有成绩，成绩分布合理（正态分布）
- 故意制造2-3个缺考数据点
- 保留之前的缺考逻辑

**执行方式：**
- 提供一个命令行参数 `--wipe` 先清空旧数据再生成
- 或者直接覆盖生成
- 生成后打印统计信息
