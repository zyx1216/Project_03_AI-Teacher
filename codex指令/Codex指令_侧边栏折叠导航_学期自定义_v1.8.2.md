## 任务一：侧边栏折叠导航（重构导航结构）

### 目标
把当前"主导航+Tab"结构改为"侧边栏折叠导航+直接渲染子功能"结构。

### 当前结构
```
侧边栏（6个主导航radio）→ 主内容区用st.tabs显示子功能
```

### 目标结构
```
侧边栏：
├── 🏠 首页（直接按钮）
├── 📅 教学日历（直接按钮）
├── 📚 备课 ▼（expander展开）
│   ├── radio: 资料管理 / AI备课 / AI出题 / 题库管理 / PPT生成
├── 📝 学业测评 ▼
│   ├── radio: 作业管理 / 智能组卷 / 成绩录入 / 作业分析 / 错题本 / 历史记录
├── 📊 学情 ▼
│   ├── radio: 学生管理 / 成绩管理 / 考试分析 / 趋势分析 / 学生画像 / 教学反思 / 期末评语 / 知识点分析
└── ⚙️ 设置（直接按钮）
```

### 实现要求

#### 1. 侧边栏导航重构（app.py）
- 首页、教学日历、设置：直接用st.button或st.radio，点击直接进入
- 备课、学业测评、学情：用st.expander包裹，里面用st.radio选择子功能
- expander的expanded状态：当前在该功能区时展开，其他折叠
- radio的label_visibility="collapsed"，不显示标签
- 全局搜索框保持在侧边栏顶部

#### 2. 主内容区渲染（app.py）
- 不再调用各模块的show()（show()里有tabs）
- 改为根据侧边栏选择直接调用对应的子功能函数
- 例如：备课+AI备课 → 直接调用lesson_plan.tab_lesson()
- 需要把各模块的tab函数从show()里提取出来，确保可以独立调用

#### 3. 状态保持（关键）
- 从子功能A切到子功能B再切回A时，A的输入状态必须保留
- 利用Streamlit的session_state自动保持（只要widget的key不变，状态会保留）
- 注意：切换页面时不要pop相关的session_state key
- AI备课的lp_plan、lp_meta、lesson_gen_args必须保留
- AI出题的multi_gen_config、multi_gen_questions必须保留
- 作业管理的hw_open_id必须保留

#### 4. 全局搜索跳转适配
- 搜索结果点击跳转时，需要同时设置主导航和子功能
- 例如：搜题目 → 备课+题库管理
- 修改_render_global_search函数，设置pending_lesson_sub_tab等key

#### 5. 页面标题
- 主内容区顶部显示当前位置，例如："📚 备课 / 🤖 AI备课"
- 用st.markdown显示面包屑导航

### 涉及文件
- app.py（主导航重构）
- modules/lesson_plan.py（确保tab函数可独立调用）
- modules/homework.py（确保tab函数可独立调用）
- modules/analysis.py（确保tab函数可独立调用）

## 任务二：教学日历增加单学期时间自定义

### 目标
教学日历支持学期设置，增加学期视图，月视图标注周次。

### 实现要求

#### 1. 学期设置（modules/calendar.py）
- 在教学日历页顶部加一个折叠区"⚙️ 学期设置"
- 包含：
  - 开学日期（st.date_input，默认2026-09-01）
  - 放假日期（st.date_input，默认2027-01-31）
  - 保存按钮
- 学期配置存到session_state，key: "calendar_semester"
- 格式：{"start": "2026-09-01", "end": "2027-01-31"}

#### 2. 周次计算函数
- 新增函数：get_week_of_semester(date, semester_start) -> int
- 计算某日期是学期第几周（开学那周为第1周）
- 新增函数：get_semester_weeks(semester_start, semester_end) -> list
- 返回学期内所有周的列表，每周包含周一到周五的日期

#### 3. 视图切换
- 在日历顶部加视图切换：[📅 月视图] [📆 学期视图]
- 月视图：现有功能不变，每天日期旁标注"第X周"
- 学期视图：
  - 显示整个学期的周次表格
  - 每行一周，显示"第X周"和周一到周五的日期
  - 有课程安排的日期高亮显示
  - 点击某天查看/编辑当天课程安排

#### 4. 学期进度显示
- 在日历顶部显示："本学期第X周，共Y周，已过Z%"
- 用st.progress显示进度条

### 涉及文件
- modules/calendar.py（主要修改）
