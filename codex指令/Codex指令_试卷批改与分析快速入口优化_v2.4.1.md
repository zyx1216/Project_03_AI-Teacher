## 第一部分：智能组卷增加试卷快速入口

### 函数：_generated_exams_panel()（约1272行）

当前：已生成试卷列表显示试卷名、学科、年级、题目数、下载按钮、删除按钮

修改：在每张试卷的操作栏增加以下按钮（只有试卷存在时才显示）：

   - 包括：各题得分率柱状图、各题难度系数、高频错题

每张试卷的操作栏改为：

## 第五部分：试卷与考试关联

### 问题
智能组卷生成的试卷（homework_type="exam"）和学情中的考试（exams表）目前没有关联。

### 解决方案
在智能组卷创建正式试卷时，自动在exams表中创建一条对应记录：
- exam_name = 试卷名
- exam_date = 当前日期
- subject = 试卷学科
- grade = 试卷年级
- total_score = 试卷总分
- source = "smart_compose"（标识来自智能组卷）
- homework_id = 试卷id（关联字段）

这样"📊查看分析"按钮就能通过homework_id找到对应的考试，跳转到考试分析。

### 数据库变更
在exams表中增加homework_id字段（INTEGER，可空）：
```sql
ALTER TABLE exams ADD COLUMN homework_id INTEGER;
```

如果exams表已有数据，不影响，新字段默认为NULL。

## 第六部分：逐题分析功能（智能组卷内）

### 文件：modules/homework.py
### 新增函数：_exam_question_analysis(exam_id)

在智能组卷的"📈 逐题分析"按钮点击后，显示：

1. **各题得分率柱状图**
   - X轴：题号
   - Y轴：得分率（0-100%）
   - 颜色：得分率<60%红色，60-80%黄色，>80%绿色

2. **各题难度系数**
   - 难度系数 = 1 - 平均得分率
   - 难度等级：易(<0.3)、中(0.3-0.7)、难(>0.7)

3. **高频错题TOP5**
   - 按错误率排序，显示前5题
   - 每题显示：题干、错误率、知识点

4. **知识点得分率**
   - 按知识点分组，计算平均得分率
   - 用横向柱状图展示

### 数据来源
从homework_question_scores表中获取该试卷的逐题批改数据。
如果没有数据，显示提示"请先到「批改与分析」完成逐题批改"。
