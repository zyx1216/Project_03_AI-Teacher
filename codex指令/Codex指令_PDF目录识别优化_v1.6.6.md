## 三、具体修改内容

### 3.1 新增函数：正则提取目录

在 `material_service.py` 中新增函数：

```python
def extract_toc_by_regex(text: str) -> list[dict]:
    """
    用正则表达式从目录文本中提取章节标题和页码。
    返回 [{"title": "章节名", "page": 页码}, ...]
    提取失败返回空列表。
    """
```

**正则匹配规则**（按优先级）：
1. 标准目录格式：`章节标题 ...... 页码`（中间是省略号或点号）
2. 章节标题 + 空格 + 页码
3. 支持的章节标题类型：
   - 第X单元、第X章、第X节、第X课
   - 综合实践、数学好玩、总复习
   - 任意文字 + 省略号 + 数字

**实现要点**：
- 逐行扫描目录文本
- 匹配行末的数字作为页码
- 匹配行首到省略号之间的文字作为标题
- 去掉标题前后的空格和省略号
- 页码必须是正整数
- 按页码升序排序
- 去掉重复的章节

### 3.2 新增函数：自动检测页码偏移

```python
def detect_page_offset(file_bytes: bytes, toc_pages: list[dict]) -> int:
    """
    自动检测PDF页码和书实际页码的偏移量。
    返回偏移量（PDF页码 = 实际页码 + 偏移量）。
    检测失败返回0。
    """
```

**检测逻辑**：
1. 找到目录页在PDF中的页码（包含"目录"的页面）
2. 取目录中第一个章节的实际页码
3. 在PDF中搜索第一个章节标题出现的页面
4. 偏移量 = 章节标题出现的PDF页码 - 目录中的实际页码
5. 如果找不到，用目录页的PDF页码 - 5作为估算偏移量

### 3.3 修改函数：detect_pdf_chapters

修改现有的 `detect_pdf_chapters` 函数，改为：

1. **第一步：提取目录页文本**
   - 扫描前10页，找到包含"目录"的页面
   - 取目录页及后面2页（共3页）的文本
   - 如果找不到"目录"，取前5页文本

2. **第二步：正则提取（优先）**
   - 调用 `extract_toc_by_regex` 提取章节
   - 如果提取到至少3个章节，使用正则结果
   - 自动检测页码偏移，校正所有章节的页码

3. **第三步：AI识别（备选）**
   - 如果正则提取失败（少于3个章节），用AI识别
   - AI识别后也自动检测页码偏移

4. **第四步：返回结果**
   - 返回校正后的章节列表
   - 同时返回检测到的偏移量（供界面显示）

### 3.4 修改章节编辑界面

在 `lesson_plan.py` 的资料详情页面，修改章节编辑部分：

1. **显示页码偏移信息**
   - 在章节表格上方显示："自动检测到页码偏移：X页"
   - 显示："PDF页码 = 实际页码 + X"

2. **支持手动修改偏移量**
   - 增加一个输入框："页码偏移量（可手动调整）"
   - 用户修改偏移量后，自动重新计算所有章节的PDF页码
   - 提供"重新自动检测"按钮

3. **章节表格保持可编辑**
   - 章节标题、层级、页码都可以手动修改
   - 修改后实时预览章节内容

### 3.5 修改函数：build_chapters_from_pdf_pages

确保按校正后的PDF页码正确提取章节内容：
- 每个章节的内容 = 从该章节起始页到下一章起始页的前一页
- 最后一个章节到PDF末尾
- 页码超出范围时自动修正

## 四、界面交互流程

### 4.1 导入PDF后的流程

1. 用户上传PDF
2. 系统自动提取文本
3. 系统自动识别目录（正则优先，AI备选）
4. 系统自动检测页码偏移
5. 显示章节列表（带页码偏移信息）
6. 用户可以：
   - 手动修改章节标题
   - 手动修改页码偏移量
   - 手动修改单个章节的页码
   - 点击"重新自动检测"
7. 用户确认后，按页码划分章节内容
8. 保存资料

### 4.2 页码偏移说明

在界面上增加说明文字：
```
💡 页码偏移说明：
PDF前面有封面、扉页等页面，导致PDF页码和书的实际页码不一致。
例如：目录显示第一单元在第2页，但PDF中实际在第6页，偏移量为4。
系统会自动检测偏移量，你也可以手动调整。
```

## 六、注意事项

1. **向后兼容**：保留现有的AI识别功能，正则是新增的优先方案
2. **错误处理**：正则和AI都失败时，回退到原来的全文作为一个章节
3. **性能优化**：正则提取比AI快很多，优先使用正则
4. **页码范围**：校正后的页码必须在1到PDF总页数之间
5. **用户体验**：自动检测后给用户明确的反馈，让用户知道用的是正则还是AI
6. **代码注释**：所有新增函数必须有详细的中文注释
