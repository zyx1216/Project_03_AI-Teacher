## 功能1：智能组卷——双向细目表

### 1.1 功能位置
在智能组卷页（modules/homework.py中tab_smart_compose函数内），组卷完成后，在"导出试卷"按钮旁边新增"📊 查看双向细目表"按钮。
同时在组卷设置阶段，新增"细目表预览"Tab，可边选题边看细目表。

### 1.2 双向细目表结构
- 横轴：知识点（从该学科该年级的题库中提取所有知识点）
- 纵轴：难度等级（基础 / 中等 / 提高）
- 每个格子显示：题目数量 + 分值（如"3题/15分"）
- 最后一行：各知识点的总分值和占比
- 最后一列：各难度的总分值和占比
- 右下角：总分

### 1.3 功能流程
1. 用户选题后，系统自动计算双向细目表
2. 细目表用st.dataframe展示，支持：
   - 点击格子高亮显示对应的题目
   - 鼠标悬停显示该格子的题目列表
3. 支持手动调整：
   - 点击格子后弹出该格子的题目列表
   - 可移除某题或替换为同知识点同难度的其他题
   - 调整后细目表实时更新
4. 导出试卷时，细目表作为附录附在试卷末尾

### 1.4 技术实现
- 新增服务层函数：utils/smart_compose_service.py 中新增：
  - build_specification_table(questions) -> dict（返回细目表数据）
  - get_questions_by_cell(questions, knowledge_point, difficulty) -> list
- 数据结构：
  ```python
  {
      "knowledge_points": ["知识点1", "知识点2", ...],
      "difficulties": ["基础", "中等", "提高"],
      "cells": {
          ("知识点1", "基础"): {"count": 2, "score": 10, "question_ids": [1, 2]},
          ...
      },
      "row_totals": {"知识点1": {"count": 5, "score": 25}, ...},
      "col_totals": {"基础": {"count": 3, "score": 15}, ...},
      "total": {"count": 10, "score": 100}
  }
  ```
- 知识点提取：从questions表的knowledge_point字段提取，去重排序
- 难度映射：题目difficulty字段（1=基础，2=中等，3=提高）

### 1.5 UI要求
- 细目表用st.dataframe，设置use_container_width=True
- 格子背景色根据题目数量渐变：少（浅红）→ 适中（浅黄）→ 多（浅绿）
- 用st.column_config设置数值列格式
- 点击格子后用st.dialog展示该格子的题目列表，支持移除操作
- 细目表下方显示"知识点覆盖率"和"难度分布"两个指标卡片

### 1.6 导出增强
- 导出试卷Word时，在试卷末尾新增"双向细目表"页面
- 用python-docx的table功能生成细目表
- 表头加粗，格子居中对齐

## 功能2：学情分析——知识点掌握追踪

### 2.1 功能位置
在知识图谱页（modules/analysis.py中tab_knowledge函数内），现有内容下方新增"📈 知识点掌握追踪"区域。
同时在学生画像页（tab_student_profile）新增"个人知识点追踪"子区域。

### 2.2 功能流程（班级维度）
1. 用户选择学科（下拉框，从有成绩数据的学科中提取）
2. 系统自动提取该学科所有出现过的知识点
3. 用户选择1-3个知识点进行对比追踪（多选框）
4. 系统查询历次考试/作业中这些知识点的掌握率
5. 生成折线图：横轴为考试时间，纵轴为掌握率（0-100%），每条线一个知识点
6. 图表下方显示：
   - 各知识点的趋势判断：上升↑ / 下降↓ / 稳定→
   - AI分析：为什么会有这个趋势（结合考试难度、教学内容等）
   - 教学建议：针对下降知识点给出改进建议

### 2.3 功能流程（学生维度）
1. 在学生画像页，选择学生后
2. 显示该学生各知识点的掌握率追踪折线图
3. 与班级平均水平对比（班级平均线用灰色虚线）
4. 标注该学生的薄弱知识点和优势知识点

### 2.4 技术实现
- 数据来源：
  - 考试成绩：scores表 + exams表（按考试时间排序）
  - 作业成绩：homework_scores表 + homeworks表
  - 知识点关联：questions表的knowledge_point字段
  - 需要通过homework_questions关联作业和题目，再关联知识点
- 新增服务层函数：utils/knowledge_graph_service.py 中新增：
  - get_knowledge_trend(session, subject, knowledge_points, class_id=None) -> dict
  - get_student_knowledge_trend(session, student_id, subject) -> dict
- 掌握率计算：某知识点在某次考试中的得分率 = 该知识点所有题目的实得分总和 / 满分总和
- 趋势判断：
  - 最近3次数据，线性回归斜率 > 0.02 → 上升
  - 斜率 < -0.02 → 下降
  - 否则 → 稳定
- AI分析：调用LLM，传入知识点名称、历次掌握率数据、考试名称，生成分析和建议

### 2.5 UI要求
- 折线图用plotly，设置：
  - 每条线不同颜色
  - 数据点显示具体数值
  - 班级平均线用灰色虚线（学生维度）
  - 图表高度400px
- 知识点选择用st.multiselect，最多选3个
- 趋势判断用emoji+文字：🟢上升 / 🔴下降 / 🟡稳定
- AI分析用st.expander折叠，默认展开
- 教学建议用蓝色提示框（st.info）

### 2.6 数据处理注意事项
- 如果某次考试没有该知识点的题目，掌握率记为None，折线图中断（不连线）
- 如果某知识点只出现过1次，不做趋势判断，提示"数据不足"
- 考试时间排序：按exam_date字段升序
- 知识点名称统一：去除前后空格，统一大小写
