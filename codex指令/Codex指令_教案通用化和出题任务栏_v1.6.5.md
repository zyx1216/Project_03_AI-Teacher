## 三、修改2：AI出题功能增加任务栏

### 3.1 修改文件
- `modules/lesson_plan.py`（主要修改）
- `utils/question_service.py`（辅助函数）

### 3.2 功能设计

#### 3.2.1 任务栏位置
- 位置：在题型选择表格（data_editor）的下方，生成题目按钮的上方
- 标题："📋 出题任务栏"

#### 3.2.2 任务数据结构
每个任务包含：
- task_id: 唯一标识（时间戳或自增ID）
- subject: 学科（语文、数学、英语等）
- grade: 年级（一年级、二年级...高三）
- question_type: 题型
- difficulty: 难度（1基础、2中等、3拓展）
- count: 数量
- material_id: 关联资料ID（可选）
- knowledge_points: 知识点（可选）
- extra: 其他要求（可选）
- created_at: 创建时间

#### 3.2.3 任务栏UI布局
```
📋 出题任务栏（已保存 N 个任务）
┌─────────────────────────────────────────────────────────────┐
│ [勾选] 学科  年级    题型    难度  数量  知识点    [删除]  │
│ [✓]   数学  三年级  选择题  基础  10    混合运算  [🗑️]   │
│ [✓]   语文  五年级  填空题  中等  5     课文理解  [🗑️]   │
│ [ ]   英语  初一    阅读题  拓展  3     阅读理解  [🗑️]   │
├─────────────────────────────────────────────────────────────┤
│ [➕ 添加当前配置为任务]  [🧹 清空所有任务]                  │
└─────────────────────────────────────────────────────────────┘
```

#### 3.2.4 交互逻辑
1. **添加任务**：
   - 用户在上方配置区设置好年级、学科、题型、难度、数量、知识点等
   - 点击"➕ 添加当前配置为任务"按钮
   - 当前配置被保存为一个任务，添加到任务栏
   - 配置区清空，准备添加下一个任务

2. **删除任务**：
   - 每个任务右侧有"🗑️"删除按钮
   - 点击后删除该任务

3. **勾选任务**：
   - 每个任务左侧有复选框
   - 勾选的任务会在生成时被处理

4. **清空所有任务**：
   - 点击"🧹 清空所有任务"按钮
   - 清空任务栏中的所有任务

5. **生成题目**：
   - 点击"🤖 生成勾选任务的题目"按钮
   - 遍历所有勾选的任务
   - 按任务的学科和年级分别生成题目
   - 生成结果按学科分组显示
   - 每个任务的题目可以单独预览、保存

#### 3.2.5 任务持久化
- 任务保存到 `data/question_tasks.json` 文件
- 页面加载时自动恢复已保存的任务
- 任务增删时自动保存到文件
