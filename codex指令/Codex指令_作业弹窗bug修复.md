# Codex 执行指令：作业弹窗bug修复

## 任务目标

修复作业页两个问题：
1. 进入作业页时，新建作业弹窗自动弹出
2. 学科选择器在弹窗外部，需要放到弹窗内部

---

## Bug 1：新建作业弹窗自动弹出

**问题：** 进入作业功能区时，新建作业弹窗自动触发打开，不是用户点了按钮才打开。

**原因：** 可能是 `st.session_state["hw_new_dialog_open"]` 默认是 True，或者切换页面时没重置。

**修复：**
- 进入作业页时，`hw_new_dialog_open` 默认设为 False
- 只有用户点了"新建作业/试卷"按钮，才设为 True
- 切换到其他页面再回来时，弹窗状态要重置

---

## Bug 2：学科选择器放到弹窗内部

**问题：** 现在学科选择器在作业列表上方（外部），用户希望在新建作业弹窗内部。

**修复：**
- 把作业列表上方的学科选择器删掉
- 在新建作业弹窗内部加学科选择器
- 位置：在类型选择之后，总分/用时之前
- 默认值："数学"
- key：`new_homework_subject`

---

## 具体改动

### `modules/homework.py`

1. **作业管理Tab开头：**
   - 删除作业列表上方的学科选择器
   - 只保留作业列表和筛选

2. **新建作业弹窗 `_new_homework_dialog()`：**
   - 在类型选择之后，加学科选择器
   - 代码大概这样：
     ```python
     st.selectbox("学科", SUBJECT_NAMES, key="new_homework_subject")
     ```
   - 创建作业时，把这个学科值传进去

3. **弹窗打开状态：**
   - 进入作业页时，强制设 `st.session_state["hw_new_dialog_open"] = False`
   - 确保只有点按钮才打开

4. **作业列表过滤：**
   - 作业列表不再按外部学科过滤
   - 或者：作业列表还是按学科过滤，但学科选择器放在作业列表上方，新建作业弹窗里的学科选择器是单独的（创建时用）

---

## 验收标准

1. ✅ 进入作业页，弹窗不自动弹出
2. ✅ 只有点"新建作业/试卷"按钮，弹窗才打开
3. ✅ 新建作业弹窗内部有学科选择器
4. ✅ 创建作业时，学科正确保存
5. ✅ 全量测试通过，零回归

---

3. 把学科选择器移到弹窗内部
4. 跑测试验证
