结果：整个文档被当成1个大章节，没法按课文选择章节来生成教案或出题。

### 1. 增强一级章节识别（单元/章）

除了现有的"第X单元/第X章"，还要识别：

#### 1.1 北师大版数学单元名
北师大版数学教材的目录结构是：
```
第一单元 混合运算
  1 小熊购物
  2 买文具
  3 过河
  练习一
```

规则：
- 识别"第X单元"后面跟的单元名（如"第一单元 混合运算"）
- 一级标题格式：`第X单元\s+(\S+)` → 标题为"第一单元 混合运算"

#### 1.2 语文教材单元
语文教材的单元结构：
```
第一单元
阅读
  1 大青树下的小学
  2 花的学校
口语交际
  我的暑假生活
习作
  猜猜他是谁
语文园地
```

### 2. 增强二级章节识别（课文/栏目）

#### 2.1 数字开头的课文标题
识别规则：行首是数字（1-99），后面跟空格或点号，然后是课文标题

格式：
- `1 大青树下的小学`
- `1. 小熊购物`
- `2　花的学校`（全角空格）

判断条件：
- 行首1-2位数字
- 后面跟空格（半角或全角）或点号
- 标题长度2-30字
- 不是目录行（已经有is_toc_line过滤）

#### 2.2 固定栏目识别
识别以下语文固定栏目为二级章节：
- `口语交际`
- `习作`
- `习作例文`
- `语文园地`
- `综合性学习`
- `写字`
- `识字`

判断条件：
- 行首精确匹配以上栏目名
- 后面没有其他文字（或只有序号）
- 不是目录行

#### 2.3 数学练习/复习栏目
识别以下数学固定栏目：
- `练习一`、`练习二`...`练习二十`
- `整理与复习`
- `总复习`
- `数学好玩`
- `营养午餐`（综合实践）

判断条件：
- 行首匹配"练习+数字"
- 或精确匹配"整理与复习"、"总复习"等

### 3. 章节层级结构

修复后章节层级应该是：

```
第一单元 混合运算（level=1）
  ├─ 1 小熊购物（level=2）
  ├─ 2 买文具（level=2）
  ├─ 3 过河（level=2）
  └─ 练习一（level=2）

第二单元 观察物体（level=1）
  ├─ 看一看（一）（level=2）
  └─ 看一看（二）（level=2）
```

语文教材的层级：
```
第一单元（level=1）
  ├─ 1 大青树下的小学（level=2）
  ├─ 2 花的学校（level=2）
  ├─ 口语交际（level=2）
  │   └─ 我的暑假生活（level=3）
  ├─ 习作（level=2）
  │   └─ 猜猜他是谁（level=3）
  └─ 语文园地（level=2）
```

---

### 4. 防误判规则

增强识别的同时，要避免误判：

1. **不要把正文里的数字当成课文标题**：
   - 正文里的"1. xxx"如果是普通段落，不要当成章节
   - 判断条件：课文标题应该是单独一行，前后有空行或页码分隔

2. **不要把目录行当成章节**：
   - 已经有is_toc_line过滤，目录行不参与章节识别
   - 目录行特征：标题+点线+页码

3. **不要重复识别**：
   - 如果一行已经被识别为一级章节，不要再当二级
   - 一个行只能属于一个层级

4. **空章节丢弃**：
   - 如果识别出的章节内容为空（只有标题没有正文），丢弃或合并到下一个章节
