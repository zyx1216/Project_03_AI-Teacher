### 问题1：删除重复的章节选择，合并搜索和选择

**当前问题：**
- AI备课有两套章节选择：
  1. `_lesson_material_picker()` 函数中的"章节搜索与选择"（关键词搜索框 + 多选框）
  2. `tab_lesson()` 函数中的"章节筛选多选 + 手动输入框"
- 两套功能重复，生成教案时两套结果都传进去了，容易混淆

**修复方案：**

1. **删除第二套章节选择**（`tab_lesson()` 中的）：
   - 删除 `ch_c1, ch_c2 = st.columns(2)` 及以下的章节筛选多选框
   - 删除 `chapter_manual` 手动输入框
   - 删除 `chapter = (chapter_manual.strip() or "、".join(chapter_pick))` 这行
   - 生成教案时，`chapter` 参数直接用 `chapters`（第一套返回的选中章节列表），用"、".join() 拼接成字符串

2. **优化第一套章节选择**（`_lesson_material_picker()` 中的）：
   - **删除单独的关键词搜索框**（`keyword = st.text_input(...)`）
   - 保留 `st.multiselect` 组件，因为 Streamlit 的 multiselect 本身就支持搜索（点击下拉框后输入关键词自动过滤）
   - 修改 multiselect 的提示文字为："章节选择（输入关键词可搜索，如输入'一'可匹配'第一单元'）"
   - 修改 multiselect 的 label 为："选择章节（可搜索）"
   - 保留已选章节数量的提示文字

3. **修改生成教案的参数传递**：
   - 原来：`_generate_lesson(topic.strip(), grade, chapter.strip(), hours, style, material_id, chapters, current_subject, template_name)`
   - 修改为：`_generate_lesson(topic.strip(), grade, "、".join(chapters), hours, style, material_id, chapters, current_subject, template_name)`
   - 确保 `chapter`（字符串）和 `chapters`（列表）保持一致

4. **修改生成教案前的校验提示**：
   - 原来：`st.warning("请先在"章节搜索与选择"中勾选要使用的章节。")`
   - 修改为：`st.warning("请先在"选择章节"中勾选要使用的章节。")`

**修改文件：**
- `modules/lesson_plan.py` - `tab_lesson()` 函数（删除第二套章节选择）
- `modules/lesson_plan.py` - `_lesson_material_picker()` 函数（优化第一套章节选择）

**修复方案：**

3. **模板选择的位置**：
   - 放在课堂风格下面

### 问题3：增强PDF章节识别，支持北师大版格式

**当前问题：**
- 当前章节切分正则只能识别：
  - `第X章/节/单元/课 + 标题`（同一行）
  - `1.1 / 1.2` 这类编号格式
- 北师大版教材的格式是：
  - "第一单元"（单独一行）
  - "混合运算"（下一行，单元名称）
  - "小熊购物"（课时标题，无编号）
  - "买文具"（课时标题，无编号）
  - "练一练"（练习标题）
  - "整理与复习"（复习标题）
- 导致只能切分到大单元，切不到具体课时

**修复方案：**

1. **增强章节标题正则表达式**：
   在 `utils/material_service.py` 的 `_CHAPTER_PATTERNS` 中增加以下模式：
   
   ```python
   _CHAPTER_PATTERNS = [
       # 原有模式1：第X章/节/单元/课 + 标题（同一行）
       re.compile(r"^\s*第\s*[0-9一二三四五六七八九十百零〇]+\s*[章节单元课]\s*[^\n]{0,40}$"),
       # 原有模式2：1.1 / 1.2 这类编号
       re.compile(r"^\s*[0-9]{1,2}\.[0-9]{1,2}(?:\.[0-9]{1,2})?\s+[^\n]{1,40}$"),
       # 新增模式3：第X单元（单独一行，后面跟单元名称）
       re.compile(r"^\s*第\s*[0-9一二三四五六七八九十百零〇]+\s*单元\s*$"),
       # 新增模式4：特殊标题（整理与复习、总复习、数学好玩、综合实践等）
       re.compile(r"^\s*(整理与复习|总复习|数学好玩|综合实践|复习|练习|练一练)\s*$"),
   ]
   ```

2. **修改 `split_chapters()` 函数，支持"第X单元+下一行标题"合并**：
   - 当识别到"第X单元"（单独一行）时，检查下一行是否是短文本（<20字）
   - 如果是，将两行合并为一个章节标题："第X单元 单元名称"
   - 例如："第一单元" + "混合运算" → "第一单元 混合运算"

3. **增加课时标题识别（可选，基于上下文）**：
   - 在单元标题后、练习标题前的短行（<15字），可能是课时标题
   - 可以将这些短行也识别为章节
   - 但要注意不要把正文内容误认为是课时标题
   - 建议：先实现单元标题合并，课时标题识别作为可选功能，如果效果好再开启

4. **优先使用PDF书签（如果有）**：
   - 在 `_preview_pending()` 函数中，已经有"使用PDF书签"按钮
   - 确保书签功能正常工作，如果PDF有书签，优先推荐使用书签
   - 在章节预览区域增加提示："如果PDF有内置书签，建议点击'使用PDF书签'按钮，章节切分更准确"

5. **过滤目录页内容**：
   - 目录页的内容格式通常是：标题 + 页码
   - 可以在章节切分前，先过滤掉目录页内容
   - 简单方法：如果某一行后面跟着纯数字（页码），则跳过该行
   - 或者：识别"目录"标题后，跳过接下来的几页内容

**修改文件：**
- `utils/material_service.py` - `_CHAPTER_PATTERNS` 常量（增加正则模式）
- `utils/material_service.py` - `split_chapters()` 函数（支持单元标题合并）
- `modules/lesson_plan.py` - `_preview_pending()` 函数（增加书签使用提示）
