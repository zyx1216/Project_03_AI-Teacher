### 涉及文件

2. 改为宽松匹配：科目名后面跟单字"分"或"绩"时，自动剥离后缀
3. 测试用例：
   - "英语分" → "英语"
   - "语文成绩" → "语文"
   - "数学分数" → "数学"
   - "政治" → "政治"（不变）

- 年级排名和班级排名对齐

## 修复6：选择题选项排版不一致

### 涉及文件
- `utils/question_service.py`：题目生成和导出相关
- 试卷导出Word相关

### 问题现象
选择题选项：
- 路径A：每行一个选项（A. xxx 换行 B. xxx）
- 路径B：挤在一行（A. xxx B. xxx C. xxx D. xxx）

### 修复要求
统一选择题选项排版：
- **默认每行一个选项**（A、B、C、D各占一行）
- 如果选项很短（比如只有几个字），可以两列并排
- Word导出和页面预览保持一致

### 实现
在题目生成和导出的两个路径中，都用同样的格式函数：
```python
def format_choices(choices):
    """统一格式化选择题选项：每行一个"""
    return "\n".join(f"{chr(65+i)}. {choice}" for i, choice in enumerate(choices))
```
