## 第一部分：异步任务处理

### 1.1 后台任务框架

**文件：utils/task_service.py（新增）**

实现轻量级后台任务框架：
1. 任务队列：使用SQLite存储任务队列
2. 任务状态：pending / running / completed / failed
3. 任务类型：AI生成、文件导入、数据导出、批量处理
4. 后台线程执行任务，不阻塞Streamlit界面

**数据库变更**：
- 新增表background_tasks：
  - id, task_type, params(JSON), status, result(JSON), error_message,
  - progress, created_at, started_at, completed_at

### 1.2 AI生成任务异步化

**文件：utils/llm_service.py, modules/lesson_plan.py, modules/homework.py**

将耗时的AI生成任务改为异步：
1. 教案生成、题目生成、PPT生成、组卷等任务
2. 点击生成后，立即返回任务ID，显示进度
3. 后台执行，界面可切换其他功能
4. 任务完成后通知，可查看结果
5. 支持任务取消

**实现要点**：
- 使用threading.Thread执行后台任务
- 使用session_state轮询任务状态
- 任务进度实时更新（0-100%）
- 任务失败显示错误信息，支持重试

### 1.3 任务管理界面

**文件：modules/settings.py（新增任务管理标签）**

新增"📋 任务管理"：
1. 显示所有后台任务列表
2. 任务状态：等待中/进行中/已完成/失败
3. 任务进度条
4. 操作：查看结果、重试、取消、删除
5. 任务历史记录（最近7天）

## 第二部分：缓存机制

### 2.1 LLM响应缓存

**文件：utils/cache_service.py（新增）, utils/llm_service.py**

实现LLM响应缓存：
1. 缓存相同prompt的LLM响应
2. 缓存key：prompt哈希 + 模型名 + 参数
3. 缓存有效期：可配置（默认24小时）
4. 缓存存储：SQLite表 + 内存LRU缓存
5. 缓存命中率统计

**数据库变更**：
- 新增表llm_cache：
  - id, cache_key, prompt_hash, model_name, response,
  - created_at, expires_at, hit_count

### 2.2 数据查询缓存

**文件：utils/cache_service.py**

实现数据查询缓存：
1. 频繁查询的数据缓存（学生列表、考试列表、题库统计）
2. 缓存失效策略：数据变更时自动清除相关缓存
3. 缓存时间：短缓存（5分钟）+ 长缓存（1小时）
4. 内存缓存 + 数据库缓存两级

### 2.3 静态资源缓存

**文件：app.py**

1. Streamlit静态资源缓存配置
2. 图表数据缓存（相同参数的图表直接返回）
3. 文件导入结果缓存（相同文件不重复解析）

## 第三部分：数据库优化

### 3.1 查询优化

**文件：utils/db.py, 各service文件**

1. 慢查询日志：记录执行时间>100ms的查询
2. 常用查询增加索引：
   - scores表：student_id, exam_id, subject
   - homeworks表：subject, grade, homework_type, status
   - questions表：subject, grade, difficulty, knowledge_point

### 3.2 数据库连接优化

**文件：utils/db.py**

1. 连接池配置：SQLAlchemy连接池大小调整
2. 连接超时设置
3. 会话管理：确保每次请求后关闭会话
4. 数据库定期优化：VACUUM、ANALYZE

### 3.3 数据归档

**文件：utils/archive_service.py（新增）**

1. 历史数据归档：超过1年的成绩、作业数据
2. 归档到单独的archive数据库
3. 归档数据仍可查询（只读）
4. 减少主数据库体积，提升查询速度

## 第四部分：全面错误处理

### 4.1 全局异常捕获

**文件：app.py, utils/error_handler.py（新增）**

1. Streamlit全局异常捕获：所有页面函数包裹try-except
2. 友好的错误提示：不显示技术栈，显示用户可理解的提示
3. 错误自动记录：写入error_logs表
4. 错误恢复：提供"重试"、"返回首页"按钮

### 4.2 LLM调用错误处理

**文件：utils/llm_service.py**

增强LLM调用的错误处理：
1. 超时处理：默认60秒超时，可配置
2. 重试机制：失败自动重试2次，指数退避
3. 降级策略：主模型失败自动切换备用模型
4. 限流处理：检测到限流时自动等待
5. 错误分类：网络错误、API错误、内容过滤、其他

### 4.3 文件操作错误处理

**文件：各文件导入导出功能**

1. 文件格式验证：上传前验证文件类型和大小
2. 解析错误处理：文件损坏、格式错误时友好提示
3. 大文件处理：超过100MB提示，分块处理
4. 编码处理：自动检测文件编码（UTF-8/GBK）

### 4.4 数据库错误处理

**文件：utils/db.py**

1. 数据库锁定处理：SQLite锁定时重试
2. 事务回滚：异常时自动回滚
3. 数据验证：写入前验证数据完整性
4. 数据库损坏检测：启动时检查数据库完整性
