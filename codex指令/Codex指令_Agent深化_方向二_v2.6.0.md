## 第一部分：多轮对话备课

### 1.1 对话式备课界面

**文件：modules/lesson_plan.py, utils/agent_tools.py**

在AI备课页面增加"💬 对话式备课"模式：
1. 聊天界面，教师可以用自然语言描述需求
2. AI理解需求后，主动提问澄清（如年级、学科、章节、课时）
3. 多轮对话调整教案内容
4. 对话历史保存，支持继续上次的备课对话

**实现要点**：
- 使用session_state保存对话历史
- 系统提示词设定AI角色为"资深教研助手"
- 支持上下文理解，如"再难一点"、"加个例题"、"缩短到30分钟"
- 每次对话后更新教案预览

### 1.2 AI主动澄清需求

**文件：utils/llm_service.py, utils/reference_resolution_service.py**

增强指代消解和主动澄清：
1. 当教师需求模糊时，AI主动提问：
   - "请问是哪个年级的？"
   - "这节课需要多长时间？"
   - "需要包含课堂练习吗？"
2. 支持指代理解："这个知识点"、"刚才那道题"、"上一章节"
3. 澄清问题最多3个，避免过度提问
4. 教师可跳过澄清，AI用默认值继续

### 1.3 教案迭代优化

**文件：modules/lesson_plan.py**

新增功能：
1. 教案生成后，支持"🔄 让AI优化"按钮
2. AI根据教师反馈迭代优化：
   - "太难了" → 降低难度，增加基础题
   - "太简单了" → 增加拓展题，提高难度
   - "时间不够" → 精简内容，突出重点
   - "学生基础差" → 增加复习环节，降低起点
3. 保存每个版本，支持版本对比和回滚

## 第二部分：智能教学建议

### 2.1 基于成绩的教学建议

**文件：modules/analysis.py, utils/agent_tools.py**

在考试分析页面增加"🤖 AI教学建议"：
1. 分析成绩数据，自动识别问题：
   - 某知识点得分率低 → 建议复习该知识点
   - 两极分化严重 → 建议分层教学
   - 计算类题目错误率高 → 建议加强计算训练
2. 生成具体的教学改进建议：
   - 下节课重点复习XX知识点
   - 建议增加XX类型的练习
   - 建议对XX学生进行个别辅导
3. 建议可操作化，直接关联到备课功能：
   - "根据建议生成复习课教案"按钮
   - "根据建议生成专项练习题"按钮

### 2.2 学生学习预警

**文件：modules/analysis.py**

新增功能：
1. 自动识别需要关注的学生：
   - 连续3次考试退步
   - 某科目持续低于及格线
   - 作业完成率低于60%
   - 错题重复率高
2. 生成"学生预警名单"，按风险等级排序
3. 每个预警学生显示：
   - 预警原因
   - 数据依据
   - 建议干预措施
4. 支持"生成辅导方案"按钮，AI生成个性化辅导计划

### 2.3 教学节奏建议

**文件：modules/teaching_plan_service.py**

增强教学计划功能：
1. 根据教学进度和成绩数据，建议教学节奏调整
2. 识别教学进度过快/过慢的章节
3. 建议是否需要增加课时复习
4. 生成下周教学重点建议

## 第三部分：自动化工作流

### 3.1 一键全流程

**文件：modules/lesson_plan.py, utils/agent_tools.py**

新增"🚀 一键备课全流程"功能：
1. 教师输入：学科、年级、章节、课时
2. AI自动完成：
   - 生成教案
   - 生成配套PPT
   - 生成课堂练习题
   - 生成课后作业
   - 生成单元测试卷
3. 所有产物保存，可分别查看和编辑
4. 进度显示：当前正在生成哪一步，预计剩余时间

### 3.2 工作流模板

**文件：utils/agent_tools.py**

预设工作流模板：
1. **新授课模板**：教案 + PPT + 课堂练习 + 课后作业
2. **复习课模板**：知识点梳理 + 典型例题 + 变式练习 + 测试卷
3. **试卷讲评课模板**：试卷分析 + 错题讲解 + 变式练习 + 巩固作业
4. **习题课模板**：例题讲解 + 课堂练习 + 课后作业
5. 支持自定义工作流，保存为模板

### 3.3 工作流执行监控

**文件：modules/lesson_plan.py**

新增功能：
1. 工作流执行进度条
2. 每一步执行结果预览
3. 支持暂停/继续/取消
4. 执行完成后生成"工作流报告"，列出所有产物

## 第五部分：Agent工具调用增强

### 5.1 工具注册扩展

**文件：utils/agent_tools.py**

新增可调用工具：
1. `search_material(关键词)` - 搜索资料
2. `generate_lesson_plan(参数)` - 生成教案
3. `generate_questions(参数)` - 生成题目
4. `analyze_scores(考试id)` - 分析成绩
5. `get_student_profile(学生id)` - 获取学生画像
6. `create_homework(参数)` - 创建作业
7. `compose_exam(参数)` - 智能组卷
8. `export_document(类型, 参数)` - 导出文档

### 5.2 工具调用审计

**文件：utils/agent_tools.py, utils/logger_service.py**

增强工具调用审计：
1. 记录每次工具调用：时间、工具名、参数、结果、耗时
2. 工具调用日志可查看
3. 失败的工具调用记录错误原因
4. 统计各工具使用频率和成功率

### 5.3 多工具链式调用

**文件：utils/agent_tools.py**

支持多工具链式调用：
1. AI可以连续调用多个工具完成复杂任务
2. 上一个工具的输出作为下一个工具的输入
3. 例如：分析成绩 → 识别薄弱知识点 → 生成练习题 → 创建作业
4. 链式调用过程可视化，教师可中断和调整
