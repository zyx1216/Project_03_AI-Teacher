## 三、验证标准

### 3.1 学校常规格式标准
- **教案**：教学目标、教学重难点、教学过程（导入/新授/练习/小结/作业）、板书设计、教学反思
- **试卷**：密封线、题号、分值标注、得分栏、考生信息栏、注意事项
- **成绩表格**：表头规范、科目分列、总分/平均分/排名计算正确
- **字体字号**：正文宋体小四/12pt，标题黑体/加粗

### 3.2 教材课标标准
- 章节提取与课本目录一致，不缺章、不多章、不串章
- 生成的题目和教案内容对应章节知识点，不超纲、不超年级难度
- 难度梯度合理（基础题:中档题:难题 ≈ 7:2:1）
- 学科题型匹配（英语有听力/阅读/作文，数学有选择/填空/解答）

## 四、五大验证维度与检查点

### 4.1 模板合理性验证
| 检查项 | 验证内容 |
|--------|----------|
| 教案模板 | 是否符合学校常规教案格式？模块是否齐全？导入自定义模板后能否正确识别并套用？ |
| 试卷模板 | 密封线、题号、分值、得分栏是否完整？导出Word后格式是否错乱？ |
| 学校模板识别 | 导入学校Word/Excel模板后，系统能否正确识别模板结构？生成内容填入后导出格式是否保持原样？ |
| 模板库 | 我的模板里保存的模板能否正常复用？学科/年级标签是否正确？ |

### 4.2 资料导入与章节提取验证
| 检查项 | 验证内容 |
|--------|----------|
| PDF导入 | 文字版PDF能否正确提取文字？扫描版PDF OCR识别效果如何？ |
| 章节提取 | 自动提取的章节目录是否与课本一致？有没有多余内容？有没有遗漏？ |
| **扫描确认流程** | 导入资料后，章节提取确认弹窗是否正常？页码偏移调整是否生效？手动修正流程是否完善？ |
| 资料命名 | 导入后自动命名是否合理？学科/年级标签是否正确匹配？ |
| 资料查看 | 点击资料能否正常预览？排版是否混乱？ |

### 4.3 内容排版验证
| 检查项 | 验证内容 |
|--------|----------|
| 教案排版 | 生成的教案段落清晰、标题层级分明？导出Word后排版是否保持？ |
| 题目排版 | 选择题选项是否对齐？填空题横线长度合适？解答题留白足够？ |
| 试卷排版 | 题目之间间距合适？有没有跨页断题？密封线位置正确？ |
| 表格排版 | 成绩表格列宽合适？数据对齐？导出Excel后格式正常？ |
| 公式排版 | 数学公式、物理符号显示正常？导出后不乱码？ |

### 4.4 导入兼容性验证
| 检查项 | 验证内容 |
|--------|----------|
| **常见字段** | 学生资料导入：班级、姓名、性别、学号等常见字段名变体（"姓名"vs"学生姓名"vs"name"）能否识别？ |
| **复杂字段** | 民族、家庭住址、家长联系方式等冷门字段能否识别或正确忽略？ |
| **异常情况** | 缺列、多列、列顺序乱、合并单元格、表头不规范、空行等脏数据能否正确处理？ |
| 成绩导入 | Excel/Word/PDF/TXT格式的成绩表能否正确解析？分数列识别正确？缺考、空值、异常分数如何处理？ |
| 题目导入 | Word/Excel/文本格式的题目能否正确识别题型、题干、答案？ |

### 4.5 导出格式验证
| 检查项 | 验证内容 |
|--------|----------|
| 教案导出Word | 格式与预览一致？标题层级正确？表格不乱？ |
| 试卷导出Word/PDF | 密封线、题号、分值完整？跨页正常？ |
| 成绩导出Excel | 列对齐？公式计算正确？ |
| 报告导出PDF | 排版美观？图表正常？分页合理？ |
| 学校模板导出 | 导入学校模板后生成内容，导出后格式是否与原模板一致？ |

## 五、验证方法

### 步骤1：代码走查
阅读以下核心文件，检查逻辑是否有明显问题：
- `modules/lesson_plan.py`：备课区（资料导入、教案生成、出题）
- `modules/homework.py`：学业测评（作业、组卷、批改）
- `modules/analysis.py`：学情（学生管理、成绩管理）
- `utils/excel_handler.py`：Excel导入解析
- `utils/ocr_service.py`：OCR识别
- `utils/material_service.py`：资料导入处理
- `utils/question_service.py`：题目处理
- `utils/export_service.py`：导出功能
- `utils/parent_communication_service.py`：家校沟通
- `utils/student_report_service.py`：学生报告
- `config.py`：年级、学科、满分等配置
- `models/models.py`：数据表结构

### 步骤2：构造测试数据验证
在代码中构造模拟数据，测试以下场景：
1. 构造不同列名的学生Excel（"姓名"/"学生姓名"/"name"混用），测试导入解析
2. 构造脏数据Excel（合并单元格、缺列、空行、列顺序乱），测试容错
3. 构造不同格式的成绩表（Excel/PDF/Word描述），测试解析逻辑
4. 检查章节提取算法是否合理，有没有硬编码或逻辑漏洞
5. 检查归一化函数（性别、学科名、年级）是否覆盖常见变体

### 步骤3：检查导出逻辑
阅读导出相关代码，检查：
1. Word导出是否有固定模板格式？
2. Excel导出列顺序和格式是否合理？
3. 试卷排版是否有密封线、题号、分值？
4. 导出内容与预览是否一致？

## 八、约束

1. **只做验证和问题记录，不修改代码**
2. 所有问题必须基于真实代码逻辑，引用具体文件和行号，不凭空猜测

6. 扫描件PDF的OCR实际效果需要运行时才能完全验证，本轮重点检查代码逻辑和处理流程是否合理
7. 学科题型要符合该学段实际情况（如小学英语没有听力题，高中才有；初中物理才有电学等）
