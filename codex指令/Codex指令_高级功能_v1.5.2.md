## 第1模块：知识点掌握度分析

### 需求
在学情工作台新增一个"知识点分析"Tab。

### 功能说明
1. **选择考试**
   - 选择一场考试

2. **知识点统计**
   - 显示这张试卷考了哪些知识点
   - 每个知识点的：
     - 分值
     - 全班得分率
     - 掌握情况（优秀/良好/一般/薄弱）

3. **学生知识点掌握**
   - 选择一个学生
   - 显示他每个知识点的得分情况
   - 用颜色标注：
     - 绿色：掌握得好
     - 黄色：一般
     - 红色：薄弱

4. **薄弱知识点**
   - 自动列出全班最薄弱的3个知识点
   - 给出建议：应该再讲哪些内容

### 实现说明
- 从题目表里读取每道题的知识点标签
- 统计每个知识点的得分率
- 得分率 > 85%：优秀
- 得分率 60-85%：良好
- 得分率 40-60%：一般
- 得分率 < 40%：薄弱

### 验收
✅ 学情页有"知识点分析"Tab
✅ 可以选择考试，显示知识点统计
✅ 可以选择学生，显示他的知识点掌握情况
✅ 自动列出薄弱知识点
✅ 全量测试通过，零回归

## 第2模块：快捷键

### 需求
给常用操作加快捷键，提升效率。

### 快捷键列表
- `Ctrl + N`：新建作业
- `Ctrl + S`：保存表格修改
- `Ctrl + K`：打开搜索（如果有的话）
- `Ctrl + 1`：切换到备课工作台
- `Ctrl + 2`：切换到作业工作台
- `Ctrl + 3`：切换到学情工作台
- `Ctrl + 4`：切换到设置

### 实现说明
- Streamlit 本身不支持快捷键，需要用 `streamlit-js-ts` 或者注入 JS 来实现
- 如果太复杂，就先做最简单的几个，不要硬上

### 注意事项
- 快捷键不要和浏览器默认快捷键冲突
- 要在界面上提示老师有哪些快捷键

### 验收
✅ 常用操作有快捷键
✅ 快捷键不冲突
✅ 界面上有快捷键提示
✅ 全量测试通过，零回归

## 第3模块：教学日历

### 需求
在侧边栏新增一个"📅 教学日历"页面。

### 功能说明
1. **月视图**
   - 显示一个月的日历
   - 每天上面显示：
     - 布置了的作业
     - 安排了的考试
     - 备了的课

2. **点击某天**
   - 显示那天的详细安排
   - 可以直接从日历里新建作业/考试/备课

3. **本周概览**
   - 显示本周要做的事情
   - 待办事项提醒

### 实现说明
- 从作业表、考试表、教案表里读取数据
- 按日期排列到日历上
- 用 streamlit-calendar 或者自己画一个简单的日历

### 注意事项
- 日历不要做太复杂，简单实用就行
- 如果 streamlit-calendar 不好用，就用简单的表格代替

### 验收
✅ 侧边栏有"📅 教学日历"页面
✅ 有月视图，显示作业、考试、备课
✅ 点击某天显示详细安排
✅ 有本周概览和待办事项
✅ 全量测试通过，零回归
