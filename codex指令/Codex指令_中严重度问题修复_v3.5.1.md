## 修复1-3：章节提取三连问题

### 涉及文件
- `utils/material_service.py`：`is_chapter_heading` 函数（第245行附近）、`split_chapters` 函数（第279行附近）

### 问题1：目录页条目被当成章节
**现象**：带目录页的资料切出"全文(只含目录)" + "第一章 有理数 ………… 1"(空) + "第二章 ………… 15"(空) + 重复章节

**修复要求**：
1. 识别目录行模式："标题 + 点线(……或...) + 页码"
2. 目录行不计入章节内容
3. 提取出空章节（title命中但content为空）要丢弃或合并到下一个有效章节

### 问题2：章与节被压平为同级
**现象**："第一章 有理数"(内容为空) 与 "1.1 正数和负数" 并列，层级信息丢失

**修复要求**：
1. 章节结构增加 level 字段：
   - 一级：第X章、第X单元、第X节（大章节）
   - 二级：X.X（小节）
   - 三级：X.X.X（小小节）
2. 空的父章节与第一个子节合并（或保留父章节但标记为"父级"）
3. 章节选择下拉框按层级显示（如"第一章 有理数 > 1.1 正数和负数"）

### 问题3："整理与复习""本章小结"被提升为独立章节
**现象**：复习内容脱离所属章，变成独立章节

**修复要求**：
1. 识别以下模式并标记为"子节"而非"独立章"：
   - "整理与复习"
   - "本章小结"
   - "复习题"
   - "单元测试"
2. 这些内容归属到上一个一级章节下

## 修复4：成绩导入无满分上限校验

### 涉及文件
- `utils/excel_handler.py`：`_to_score` 函数（第125行附近）
- `utils/full_score_service.py`（满分配置服务）

### 问题现象
999、1e9 这样的异常分数被当作有效分数原样入库，污染均分与排名。

### 修复要求
1. 导入成绩时，根据科目和年级查询满分（如：高中数学150分，初中数学120分，小学数学100分）
2. 分数超过满分上限时：
   - 不直接入库
   - 在导入预览中标黄提示"分数超出满分上限，请确认"
   - 让用户手动修改后再导入
3. 分数为负数时同样标红提示
4. 满分配置：
   - 小学：语数英100分，其他科目100分
   - 初中：语数英120分，其他科目100分
   - 高中：语数英150分，其他科目100分
   - 支持在设置中自定义满分

## 修复5：家长/学生报告不显示满分、得分率、排名

### 涉及文件
- `utils/parent_report_service.py`：第76行、第155行附近
- `utils/student_report_service.py`

### 问题现象
报告里只显示"数学132分"，家长不知道是高是低（150分制下132是优秀，100分制下132是异常）。

### 修复要求

#### 5.1 家长报告
每个科目分数后追加参照信息：
- "数学 132分（满分150，得分率88%，班级排名5/45）"
- 得分率 = 实际分数 / 满分 × 100%
- 排名：班级排名和年级排名都要有

#### 5.2 学生报告
同样在分数旁显示：
- 得分率百分比
- 班级排名
- 年级排名

#### 5.3 分数段评价
根据得分率给出文字评价：
- 90%以上：优秀
- 80%-90%：良好
- 70%-80%：中等
- 60%-70%：及格
- 60%以下：待提高

## 修复6：学生报告表格错位、文案自相矛盾

### 涉及文件
- `utils/student_report_service.py`：`export_student_report_pdf` 函数（第211行附近）

### 问题现象
1. "成绩概览"表头与数据行错位（日期列无间距）
2. 总分显示 `250.0`（应该是250，去掉小数点）
3. "暂无明显薄弱点"却建议"先补基础概念"，文案自相矛盾

### 修复要求

#### 6.1 表格对齐
- 表头列宽与数据列宽一致
- 日期列右对齐或居中，不要贴在一起
- 数字列右对齐

#### 6.2 数字格式
- 整数分去掉 `.0`（250.0 → 250）
- 得分率保留一位小数（88.3%）

#### 6.3 文案修正
- 有薄弱点时："建议重点复习：XXX、XXX"
- 无薄弱点时："各科表现均衡，建议保持" 或 "继续保持优势科目，适当拓展提高"
- 不要出现"无薄弱点却建议补基础"的矛盾

## 修复7：Word字体字号不符合常规

### 涉及文件
- `utils/lesson_service.py`：`_set_doc_style_font` 函数（第311行附近）
- `utils/question_service.py`：试卷导出相关

### 问题现象
- 教案Word用微软雅黑11pt
- 试卷路径A未设置字体字号
- 不符合"正文宋体小四(12pt)、标题黑体加粗"的常规要求

### 修复要求

#### 7.1 统一字体规范
所有Word导出统一使用：
- **正文**：宋体，12pt（小四），行距1.5倍
- **一级标题**：黑体，16pt（三号），加粗
- **二级标题**：黑体，14pt（四号），加粗
- **三级标题**：宋体，12pt，加粗
- **密封线文字**：宋体，10.5pt（五号）

#### 7.2 中文字体设置
在python-docx中正确设置中文字体：
```python
from docx.oxml.ns import qn
run.font.name = 'Times New Roman'  # 西文
run._element.rPr.rFonts.set(qn('w:eastAsia'), '宋体')  # 中文
```

#### 7.3 适用范围
- 教案导出Word
- 试卷导出Word（学生卷/教师卷）
- 学校模板填充后的Word
