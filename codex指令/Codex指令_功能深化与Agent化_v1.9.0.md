## 阶段一：Agent化核心（功能1-2）

### 功能1：自然语言指令入口

#### 实现要求
1. 在侧边栏全局搜索框下方新增"🤖 AI助手"输入框
2. 支持自然语言指令，AI解析意图后自动调用对应功能
3. 支持的指令类型：
   - **出题类**："帮我出一份初一数学第三章的试卷，难度中等，10道选择+5道填空+3道大题"
   - **备课类**："下周三的数学课备一下，用北师大版教材"
   - **分析类**："分析一下张三最近5次考试的成绩趋势"
   - **查询类**："最近有什么作业截止""题库里有多少道数学题"
4. 实现方式：
   - 用LLM做意图识别（intent classification）
   - 提取关键参数（学科、年级、章节、题型、数量、难度等）
   - 根据意图调用对应服务层函数
   - 返回执行结果摘要
5. 指令执行历史保留在侧边栏，可点击重新执行
6. 无法识别的指令给出友好提示和建议

#### 涉及文件
- app.py（侧边栏新增AI助手输入框）
- utils/agent_service.py（新建，意图识别和任务执行）
- utils/agent_intents.py（新建，意图定义和参数提取）

---

### 功能2：多步任务规划

#### 实现要求
1. 复杂指令自动拆解为多步执行
2. 支持的多步任务：
   - "准备下周一的数学课并出一份课后作业"
     - 第一步：识别教材和章节
     - 第二步：生成教案
     - 第三步：根据教案生成作业
     - 第四步：汇总结果
   - "分析班级成绩并生成教学反思"
     - 第一步：获取最近考试数据
     - 第二步：分析薄弱知识点
     - 第三步：生成教学反思
3. 执行过程中显示进度（"正在执行第1步/共3步"）
4. 每一步执行结果可查看，支持中途取消
5. 多步任务的中间结果保存到session_state，支持回退修改

#### 涉及文件
- utils/agent_service.py（多步规划逻辑）
- utils/agent_planner.py（新建，任务拆解和规划）

## 阶段二：功能深化（功能3-5）

### 功能3：学生知识图谱/薄弱点分析

#### 实现要求
1. 在学情区新增"🧠 知识图谱"Tab（替换或补充现有知识点分析）
2. 基于历次考试和作业数据，构建每个学生的知识掌握度：
   - 知识点掌握度 = 该知识点相关题目的正确率加权
   - 考虑时间衰减（近期考试权重更高）
   - 考虑题目难度（难题正确权重更高）
3. 展示方式：
   - 班级知识图谱：热力图（学生×知识点）
   - 个人知识图谱：雷达图或仪表盘
   - 薄弱知识点自动标记（掌握度<60%标红，60-80%标黄）
4. 薄弱点分析：
   - 自动识别每个学生的Top5薄弱知识点
   - 给出针对性练习推荐（从题库选题）
   - 一键生成"薄弱点专项练习"作业
5. 支持按学科、年级、考试范围筛选

#### 涉及文件
- modules/analysis.py（新增知识图谱Tab）
- utils/knowledge_graph_service.py（新建，掌握度计算）
- models/models.py（如需新增表）

## 阶段三：体验优化（功能6-7）

### 功能6：操作撤销/重做

#### 实现要求
1. 关键操作支持撤销：
   - 删除题目/教案/作业/学生
   - 批量修改题目
   - 成绩导入
2. 保留最近10步操作历史
3. 实现方式：
   - 操作前自动备份相关数据到undo_stack
   - 撤销时从undo_stack恢复
   - 重做支持（redo_stack）
4. UI：
   - 页面顶部显示"↩️ 撤销"和"↪️ 重做"按钮（仅在有可撤销/重做操作时显示）

5. 切换页面时清空撤销栈（避免跨页面撤销混乱）

#### 涉及文件
- utils/undo_service.py（新建，撤销重做管理）
- app.py（顶部撤销重做按钮）
- 各模块（关键操作前调用undo_service.record）

## 注意事项

1. **分阶段执行**：每个阶段完成后验证，再进行下一阶段
2. **Agent意图识别**：用LLM做意图分类，Prompt要清晰，支持的意图要明确列出
3. **知识图谱计算**：掌握度算法要合理，考虑时间衰减和难度权重
4. **撤销重做**：只对关键操作实现，不要对所有操作都记录（性能问题）
5. **导出PDF/LaTeX/PPT**：注意中文字体支持，数学公式正确渲染
6. **快捷键**：输入框聚焦时禁用全局快捷键，避免用户输入时触发
7. **不要破坏现有功能**：所有修改必须向后兼容
8. **LLM调用超时**：Agent意图识别设置30秒超时，多步任务每步单独超时
9. **如果遇到Streamlit限制**，优先保证功能可用，UI可以后续优化
