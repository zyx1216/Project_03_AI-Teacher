## 实现方案

### 1. 静态文件服务
- 上传的PDF文件保存在 `data/uploads/` 目录
- 用 Streamlit 的 static folder 功能，或者自己写一个静态文件服务
- 让PDF文件可以通过URL直接访问，比如：`http://localhost:8501/static/uploads/xxx.pdf`

### 2. 资料名做成链接
- 资料列表里，资料名从普通文字，改成可点击的链接
- 点击后，在新的浏览器标签页打开原始PDF
- 用 HTML 的 `<a target="_blank">` 实现，或者用 `st.link_button`

### 3. 保留现有详情页
- 现在的资料详情页（点资料名进入的页内详情）保留
- 或者：改成两个入口
  - 点资料名 → 新标签页打开原始PDF
  - 点"详情"按钮 → 进入页内详情（查看提取的文字、编辑等）

### 4. 其他格式的处理
- PDF：新标签页直接打开
- Word：新标签页下载，或者用在线预览
- 文本：还是在页内详情显示
- 网络导入：新标签页打开原网页

## 注意事项

1. **Streamlit static folder**：
   - Streamlit 1.30+ 支持 `static/` 目录作为静态文件服务
   - 如果版本不够，就把上传的PDF复制到 `static/uploads/` 目录
   - 或者用其他方式提供静态文件访问

2. **文件路径安全**：
   - 不要让用户通过URL访问到系统其他文件
   - 只允许访问 `data/uploads/` 目录下的文件

3. **大文件**：
   - PDF文件可能很大，打开慢是正常的
   - 给用户提示："正在打开PDF，请稍候..."
