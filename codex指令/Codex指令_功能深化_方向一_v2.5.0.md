## 第一部分：智能组卷增强

### 1.1 试卷模板保存与复用

**文件：modules/homework.py, utils/homework_service.py**

新增功能：
1. 在智能组卷配置页面增加"💾 保存为模板"按钮
2. 保存内容：学科、年级、资料、章节、知识点、题型题量、难度配比、总分、用时
3. 模板列表：显示已保存的模板，支持"📋 套用模板"、"✏️ 重命名"、"🗑️ 删除"
4. 套用模板后自动填充所有配置项，用户可微调后组卷

**数据库变更**：
- 新增表exam_templates：
  - id, name, subject, grade, material_id, chapters(JSON), knowledge_points(JSON),
  - type_matrix(JSON), difficulty_ratio(JSON), total_score, duration, created_at

### 1.2 难度分布可视化

**文件：modules/homework.py**

在智能组卷预览页面增加：
1. 难度分布饼图：易/中/难题目数量占比
2. 题型分布柱状图：各题型题目数量
3. 知识点覆盖表：各知识点题目数量和分值占比
4. 预估平均分：根据难度系数预估班级平均分

### 1.3 知识点覆盖率检查

**文件：modules/homework.py, utils/question_service.py**

新增功能：
1. 组卷完成后显示"知识点覆盖率"报告
2. 对比目标章节的知识点列表，标注已覆盖和未覆盖的知识点
3. 未覆盖知识点用红色标注，建议补充题目
4. 支持"🔄 补充未覆盖知识点"按钮，自动生成补充题目

## 第二部分：批改增强

### 2.3 批改进度可视化

**文件：modules/homework.py**

## 第三部分：分析增强

### 3.1 多考试对比分析

**文件：modules/analysis.py**

在考试分析页面增加"📊 多考试对比"标签页：
1. 选择2-5次考试进行对比
2. 对比维度：
   - 平均分变化趋势（折线图）
   - 各科平均分对比（分组柱状图）
   - 优秀率/及格率变化（双折线图）
   - 分数段分布变化（堆叠柱状图）
3. AI生成"考试对比分析报告"，总结进步和退步

### 3.2 班级进步追踪

**文件：modules/analysis.py**

新增功能：
1. 在趋势分析页面增加"班级进步追踪"
2. 计算每个学生的进步指数：(本次排名 - 上次排名) / 总人数
3. 进步榜：进步最大的前10名学生
4. 退步预警：退步较大的学生（退步>10%）
5. 进步分布饼图：进步/持平/退步人数占比

### 3.3 教学效果评估

**文件：modules/analysis.py, utils/stats.py**

新增功能：
1. 根据多次考试数据，评估各知识点的教学效果
2. 教学效果指标：
   - 知识点掌握率变化（教学前vs教学后）
   - 错题重复率（同一知识点反复错）
   - 进步速度（掌握率提升斜率）
3. 生成"教学效果评估报告"
4. 标注教学效果好的知识点和需要改进的知识点

## 第四部分：题库增强

### 4.1 题目标签体系

**文件：modules/lesson_plan.py, utils/question_service.py**

新增功能：
1. 每道题目支持多个标签：
   - 题型标签：选择题、填空题、解答题等
   - 难度标签：易、中、难
   - 知识点标签：对应知识点
   - 来源标签：AI生成、手动录入、外部导入
   - 自定义标签：用户自由添加
2. 题库筛选支持按标签组合筛选
3. 标签统计：各标签下的题目数量

**数据库变更**：
- 新增表question_tags：id, question_id, tag_name, tag_type
- 新增表tag_definitions：id, name, type, color

### 4.2 难度自动标定

**文件：utils/question_service.py**

新增功能：
1. 根据题目被作答的数据，自动计算难度系数
2. 难度系数 = 1 - 平均得分率
3. 难度等级：易(<0.3)、中(0.3-0.7)、难(>0.7)
4. 定期更新题目难度（每次批改后更新）
5. 显示"AI标定难度"和"用户设定难度"，可选择使用哪个

### 4.3 知识点自动标注

**文件：utils/question_service.py, utils/llm_service.py**

新增功能：
1. AI出题时自动标注知识点
2. 手动录入题目时，AI自动识别并推荐知识点
3. 支持"🔍 AI识别知识点"按钮，批量标注未标注知识点的题目
4. 知识点标注置信度显示，低置信度提示人工确认
