你是一名资深AI应用开发工程师，正在开发一个面向中小学教师的AI教学辅助系统。

**工作原则：**

## 任务目标

全面优化备课区的5个Tab：资料管理、AI备课、AI出题、题库管理、PPT生成。

## 第一批：资料管理优化

### 1.1 点击资料名查看详情
- 资料列表里，资料名做成可点击的链接
- 点一下，跳转到资料详情界面
- 详情界面显示：资料名、年级、学科、上传时间、内容预览
- 可以返回资料列表

### 1.2 导入后自动弹窗命名 + 年级切换筛选
- 现在：导入前要填资料名和年级，很麻烦
- 改成：
  1. 上传文件后，先自动识别
  2. 识别完成后，自动弹窗让老师命名
  3. 年级用下拉选择（和学科一样）
- 资料列表上方：年级切换 + 学科切换，用来筛选查找已有资料
- 删除原来的"资料名和年级编辑框"

### 1.3 导入识别支持停止/终止/进度清除
- OCR识别过程中，加一个"停止识别"按钮
- 点一下，立即停止识别
- 加一个"清除进度"按钮，清除失败的识别任务
- 显示当前识别进度："正在识别第 X / N 页..."

### 1.4 新增：支持从教材网站爬取资料
- 资料管理Tab新增"网络导入"按钮
- 输入教材网站的链接
- 自动抓取网页内容，导入为资料
- 注意：只支持公开的、可以直接访问的网页

## 第二批：AI备课优化

### 2.1 资料章节筛选定位
- 资料导入时，自动识别目录（章节结构）
- AI备课Tab：
  1. 先选学科
  2. 筛选出对应学科的已导入资料
  3. 选择资料后，显示该资料的章节列表
  4. 可以选择具体章节，或者用关键词查找章节
- AI生成教案时，只针对选中的章节，不是整本书

### 2.2 教案可编辑 + 模板切换
- AI生成教案后：
  1. 直接在AI备课Tab里显示，可自由编辑
  2. 编辑完成后，点"保存教案"按钮保存
  3. 点"导出教案"按钮导出Word
- 新增教案模板功能：
  1. 有一个"教案模板"下拉框，可切换不同模板
  2. 模板列表里，最后一行是"导入自定义模板"
  3. 可以自己命名模板，保存为自定义模板
  4. 已有几个默认模板：通用模板、语文模板、数学模板

## 第三批：AI出题全面优化

### 3.1 年级和资料筛选
- AI出题Tab：
  1. 先选年级和学科
  2. 然后选对应学科的资料（可选）
  3. AI出题时，参考选中的资料内容

### 3.2 题型随年级和学科自动变化
- 选了不同年级和学科，题型选择列表自动变化：
  - 小学数学：选择题、填空题、判断题、计算题、应用题
  - 初中数学：选择题、填空题、解答题、证明题
  - 初中语文：选择题、填空题、阅读理解、作文题
  - 初中政治：选择题、材料分析题
  - 等等，按学科和年级匹配题型

### 3.3 知识点筛选
- 新增"知识点筛选"功能
- 知识点从资料章节里同步出来
- 支持多选知识点
- AI出题时，只出选中知识点的题

### 3.4 多任务多难度批量生成
- 现在：选一个题型、一个难度，生成N道题
- 改成：
  1. 可以添加多个出题任务
  2. 每个任务：题型 + 难度 + 数量
  3. 比如：选择题×简单×5道、填空题×中等×3道、计算题×困难×2道
  4. 确认后，一次性生成所有任务的题
  5. 生成完显示预览，确认后再保存到题库
- 历史记录：
  1. 保存每次出题的历史记录
  2. 可以查看历史，重新生成类似的题
- 多科目同时生成：
  1. 可以同时选多个学科，一起出题
  2. 但不同年级不行，一次只能一个年级

## 第四批：题库管理 + PPT生成优化

### 4.1 题库管理：按知识点组卷
- 新增"按知识点组卷"功能
- 选择多个知识点，自动从题库里抽题
- 可以设置：每个知识点抽几道题、什么难度
- 自动生成一份试卷

### 4.2 新增：从历年真题导入
- 题库管理新增"导入真题"按钮
- 上传历年真题PDF/Word
- 自动识别题目，导入到题库
- 标注来源："2023年期中考试"之类的

### 4.3 PPT生成：自定义PPT模板
- PPT生成Tab：
  1. 新增"PPT模板"下拉框
  2. 有几个默认模板：简约、教育、商务
  3. 支持导入自定义PPT模板
  4. 生成PPT时，套用选中的模板
